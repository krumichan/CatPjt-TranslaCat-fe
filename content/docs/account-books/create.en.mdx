---
title: Create an account book
description: Choose a name and base currency for your first account book.
---

Start by [opening the account book screen](/en/docs/account-books/open).

## Follow these steps

1. Select **Create account book (신규 가계부 작성)** in the list.
2. Enter a **Book name (가계부명)** and choose a **Category (카테고리)**. You can select an existing category or choose **Enter manually (직접 입력)** to add a name.
3. Choose the **Base currency (기준 통화)**. Check it before saving: amounts in this book use this currency.
4. Optionally enter **This month's goal amount (이번 달 목표 금액)** and a **Description (설명)**. You can leave the goal empty.

5. Select **Save (등록)**, then open the new book card to start recording transactions.

A book category groups account books in the list. Transaction categories, such as food or transport, classify individual transactions.

## Check the result

Find the new card in the list. Open it and check that the name and base currency match your choices. You are ready to enter the first transaction.
