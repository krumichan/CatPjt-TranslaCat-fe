---
title: Add and apply recurring expenses
description: Create templates for monthly expenses and apply them as transactions to a selected month.
---

Start by [opening an account book](/en/docs/account-books/open).

## Follow these steps

1. In the recurring expense area of the book details, select **Add recurring expense (고정비 등록)**.
2. Enter a name, category, amount, monthly payment day, and starting year/month. Optionally set a store, memo, and ending year/month. Without an end month, the expense continues to repeat.

3. Select **Save (등록)**. A recurring expense is a template; applying it to transaction history is a separate step.
4. When you select a month and an unapplied-expense notice appears, check the count and total, then select **Apply recurring expenses (고정비 반영)**.

Use an expense's **… menu** for **Details (상세)**, **Edit (수정)**, **Activate / Deactivate (활성화 / 비활성화)**, or **Delete (삭제)**. Deleting a recurring expense does not delete transactions already generated from it.

## Check the result

Check the new item in the recurring expense list. If you also applied it to a month, check that the transaction appears in that month's transaction list.
