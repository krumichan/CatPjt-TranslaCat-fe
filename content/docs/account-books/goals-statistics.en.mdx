---
title: View monthly goals and statistics
description: Set monthly spending goals and review income, expenses, and spending patterns for a period.
---

Start by [opening an account book](/en/docs/account-books/open).

## Follow these steps

1. Select the **Month (월)** you want to review in the book details. Income, expenses, balance, transaction count, and spending distribution reflect the selected period.
2. Open **This month's spending goal → Set goal amount (이번 달 지출 목표 → 목표 금액 설정)**. Choose the year/month, enter a goal greater than zero, and select **Save (저장)**.

3. Use **Open monthly goal list (월별 목표 목록 열기)** to find and edit existing goals.
4. Check the goal card for spending so far, the remaining or exceeded amount, and the percentage used. If no specific month is selected, choose one first.

## Read the charts

- **Monthly expenses (월별 지출)** compares spending and goals for the selected year.
- **Expenses by category (카테고리별 지출)** and **Expenses by brand/store (브랜드·가게별 지출)** show the distribution for the selected month or all time. Branches of the same store are combined in the store chart.

## Check the result

Check the selected month and goal amount. When you change the period, the summary and charts should show the period you want to review.
