Choose a base currency for each account book and keep track of income and expenses. You can invite other members to a shared book, or analyze receipt photos and review the suggested transactions before saving them.

This guide is public. Using [account books](/en/account-books) requires you to sign in. Service links open the **English interface**. ## Troubleshooting

| Situation | What to check |
| --- | --- |
| No books or transactions appear | Check your search, category, income/expense filter, and selected period. |
| You cannot select a category | Select **Reload (다시 조회)** or use **Enter manually (직접 입력)**. |
| A receipt amount or store is incorrect | Open **Review and edit (확인·수정)** and compare it with the original before saving. See [transaction editing](/en/docs/account-books/transactions) for fields you can change after saving a receipt transaction. |
| The exchange rate could not be retrieved | Check the original currency, amount, date, and connection, then select **Check conversion again (환산 금액 다시 확인)**. |
| The same receipt appears twice | Compare the photo and suggestions, then deselect duplicate suggestions before saving. |
| You can no longer view a book | Check your signed-in account and membership. If you left or were removed, ask the owner to invite you again. |

If the problem continues, use the [Support guide](/en/docs/support) to report the screen you were using and the message shown.
