---
title: 家計簿
description: 家計簿の作成、共同利用、収支の記録、レシートのAI分析、固定費や月別の支出目標を案内します。
---

家計簿ごとに基準通貨を決めて収入・支出を記録できます。メンバーを招待して共同利用したり、レシート写真から取引候補を作成し、内容を確認して登録したりできます。

このガイドはログインせずに読めます。[家計簿の利用](/ja/account-books)にはログインが必要です。画面内の名前や金額は説明用のサンプルです。画像を押すと拡大できます。

## やりたい操作を選ぶ

<Cards>
  <Card title="家計簿を開く" href="/ja/docs/account-books/open">家計簿を検索し、使いたい家計簿の詳細画面を開きます。</Card>
  <Card title="新しい家計簿を作成する" href="/ja/docs/account-books/create">家計簿名と基準通貨を決めて、最初の家計簿を作成します。</Card>
  <Card title="収入・支出を手入力する" href="/ja/docs/account-books/manual-transactions">レシート写真を使わず、収入や支出を手入力して登録します。</Card>
  <Card title="レシート写真を選んで分析する" href="/ja/docs/account-books/receipt-upload">レシート写真を選択して分析し、取引候補を準備します。</Card>
  <Card title="レシート分析結果を確認して登録する" href="/ja/docs/account-books/receipt-review">原本と分析結果を比較し、必要な項目を修正して取引を登録します。</Card>
  <Card title="取引を探す・修正・削除する" href="/ja/docs/account-books/transactions">期間や検索語で取引を探し、詳細の確認、修正や削除を行います。</Card>
  <Card title="固定費を登録して月ごとに反映する" href="/ja/docs/account-books/fixed-costs">毎月繰り返す支出を固定費として登録し、対象月の取引に反映します。</Card>

レシートで登録する場合は、**写真を選んで分析する → 分析結果を確認して登録する** の順に進んでください。PCとモバイルで配置が異なる操作は、各ページ内のタブで確認できます。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 一覧や取引が表示されません | 検索語・カテゴリ・収支の区分・期間を確認します。 |
| カテゴリを選べません | 再取得するか、**直接入力** を利用します。 |
| レシートの金額や店名が違います | 登録前に **確認・修正** で原本と照合します。登録済みのレシート取引で修正できる項目は、[取引を探す・修正・削除する](/ja/docs/account-books/transactions)で確認してください。 |
| 為替レートを取得できません | 原通貨・金額・日付と接続状態を確認し、**換算額を再確認** を押します。 |
| 同じレシートが2件あります | 原本と候補を比較し、重複した候補の選択を解除して登録します。 |
| 家計簿を見られなくなりました | ログイン中のアカウントと参加状況を確認します。退出やメンバー削除があった場合は、オーナーに再招待を依頼してください。 |

解決しない場合は [サポートガイド](/ja/docs/support) を参考に、利用していた画面と表示された案内をお知らせください。
