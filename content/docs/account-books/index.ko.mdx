가계부별로 기준 통화를 정하고 수입과 지출을 기록할 수 있어요. 함께 쓰는 가계부에는 멤버를 초대하고, 영수증 사진을 분석해 거래 후보를 확인한 뒤 등록할 수 있어요.

이 가이드는 로그인 없이 읽을 수 있으며, [가계부 사용](/ko/account-books)에는 로그인이 필요해요. 화면 캡처의 이름과 금액은 설명을 위한 예시예요. 이미지를 누르면 확대할 수 있어요.

영수증으로 등록하려면 **사진 올리고 분석하기 → 분석 결과 확인하고 등록하기** 순서로 따라가세요. PC와 모바일의 배치가 다른 부분은 각 작업 안의 탭에서 확인할 수 있어요.

## 자주 막히는 부분

| 상황 | 확인할 내용 |
| --- | --- |
| 목록이나 거래가 없어요 | 검색어, 카테고리, 수입·지출 구분과 선택한 기간을 확인해요. |
| 카테고리를 고를 수 없어요 | **다시 조회**를 누르거나 **직접 입력**을 이용해요. |
| 영수증 금액이나 점포가 틀려요 | 등록 전에 **확인·수정**에서 원본과 비교해 고쳐요. 이미 등록한 영수증 거래의 수정 가능 항목은 [거래 찾기·수정·삭제하기](/ko/docs/account-books/transactions)에서 확인해요. |
| 환율을 가져오지 못했어요 | 원본 통화·금액·날짜와 연결 상태를 확인하고 **환산 금액 다시 확인**을 눌러요. |
| 같은 영수증이 두 번 보여요 | 원본과 후보를 비교하고 중복 후보를 선택 해제한 뒤 등록해요. |
| 가계부를 더 이상 볼 수 없어요 | 내 계정과 참여 상태를 확인해요. 나갔거나 멤버에서 삭제된 가계부라면 오너에게 다시 초대를 요청해 주세요. |

계속 문제가 생기면 [고객센터 가이드](/ko/docs/support)를 참고해 이용 중인 화면과 표시된 안내를 알려 주세요.
