title: Open an account book

---

## Follow these steps

<Tabs items={["PC", "Mobile"]} groupId="guide-device-en">
  <Tab value="PC">
    1. Select **Account books (가계부)** in the left menu.
    2. Search by book name or description, or narrow the list with **All categories (전체 카테고리)**.
    3. Select a book card to open its details.

    <GuideScreenshot
      src="/images/guides/ko/account-books-pc.jpg"

      title="PC: choose an account book"
      caption="Korean interface with example data. Select a card to open the book; the icons lead to member management, editing, or deletion. Available icons depend on your permissions."
      width={1280} height={900} step={1} locale="en"
    />
  </Tab>
  <Tab value="Mobile">
    1. Open the **☰ menu** at the top left and select **Account books (가계부)**.
    2. Use search and the category filter, then select a book card.
    3. In the details, scroll down to see charts, recurring expenses, and transactions.

    <GuideScreenshot
      src="/images/guides/ko/account-books-mobile.jpg"
      alt="Korean mobile account book list with search, create button, and vertically arranged cards"
      title="Mobile: choose a book from the list"
      caption="Korean mobile interface with example data. Each book summary wraps to fit the narrower screen."
      width={390} height={844} step={1} locale="en"
    />
  </Tab>
</Tabs>

If a narrow PC window shows a menu button, follow the Mobile instructions. Creating a book and saving transactions work the same way on both layouts.

## Check the result

The book details should show its name, base currency, and income/expense summary. If the list is empty, create an account book first.
