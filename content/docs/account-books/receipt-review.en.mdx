---
title: Review and save receipt results
description: Compare analysis results with the original receipts, correct the details, and save selected transactions.
---

Start by [opening an account book](/en/docs/account-books/open).

## Follow these steps

Complete [receipt photo upload and analysis](/en/docs/account-books/receipt-upload) first, so suggested transactions are visible.

Analysis alone does not save transactions. Choose and review the items you want to save under **Review receipt transactions (영수증별 거래 확인)**.

## Compare with the original and save

1. Compare each suggestion's transaction name, store, category, date, original currency, and amount with the photo. Use **Review and edit (확인·수정)** to resolve **Needs review (확인 필요)** labels or warnings.
2. Under **Receipt payment and exchange rate details (영수증 결제·환율 세부 정보)**, check the branch, time, purchase total, payment evidence, cash tendered, and change against the original. Use the **Review with original (원본과 함께 확인)** preview when shown. If the receipt has no branch information and a corresponding confirmation is displayed, select it.
3. Distinguish points and discounts from the amount actually paid. If an advance payment also needs to be recorded now, follow **Other payment / unrecorded prepayment (기타 결제·미등록 선결제)**. Do not include advance payments you have already recorded.
4. If you change the amount, currency, or date, or conversion needs checking, select **Check conversion again (환산 금액 다시 확인)**. Check the amount applied to the book, exchange rate, and actual rate reference date. A warning appears if the transaction date has no rate and an earlier published rate is used.
5. Select **Apply changes (변경사항 적용)** to apply your edits. If **Confirm current source and entries reviewed (현재 원본과 입력값 확인 완료)** is shown, compare the original and select it first. Changing an entry again may require another original-receipt or conversion check.
6. Select the suggestions to save, then select **Add N selected transactions (선택한 N건 등록)**. **Select only items ready to add (등록 가능한 항목만 선택)** can select suggestions that are ready to save.

If **Add missing receipt area (누락 영수증 영역 추가)** appears on a photo, mark the receipt area that analysis missed, or use **Use full photo (전체 사진 사용)** to add a suggestion. This does not save a transaction: enter the required values and complete the checks shown. If this control is unavailable, take a separate photo of the missed receipt and analyze it again.

<Callout title="If the save button is disabled">
  Check the selected suggestions' **Current reasons preventing registration (현재 등록 차단 사유)**. Verify required values, purchase total and payment totals, and a valid conversion result. Complete the original-receipt confirmation when it is shown. Apply or cancel any pending name or amount edits. If saving fails, the suggestions remain so you can check the message and retry.
</Callout>

## Check the result

Look for the success message and saved transactions in the list. If you saved only some suggestions, continue reviewing the remaining items and any reasons blocking them.
