먼저 [가계부 열기](/ko/docs/account-books/open)를 따라 화면을 열어 주세요.

## 순서대로 따라 하기

[영수증 사진 올리고 분석하기](/ko/docs/account-books/receipt-upload)를 마쳐 후보가 표시된 상태에서 시작해요.

분석만으로 거래가 저장되지는 않아요. **영수증별 거래 확인**에서 저장할 항목을 고르고 확인해 주세요.

## 원본과 비교하고 등록하기

1. 각 후보의 거래명, 점포, 카테고리, 거래일, 원본 통화와 금액을 원본 사진과 비교해요. **확인 필요**나 경고가 표시된 항목은 **확인·수정**에서 보완해요.
2. 원본 사진과 비교하면서 **영수증 결제·환율 세부 정보**에서 지점·시각·구매총액·결제 근거·현금 지급액·거스름돈을 확인해요. **원본과 함께 확인** 미리보기가 표시되면 함께 이용하고, 지점 표기가 없는 경우 그에 대한 확인 항목이 보이면 선택해요.
3. 포인트·할인과 실제 결제 금액을 구분해요. 선결제를 이번에 함께 기록해야 한다면 화면의 **기타 결제·미등록 선결제** 안내를 확인하고, 이미 기록한 선결제를 중복 포함하지 않아요.
4. 금액·통화·날짜를 바꾸거나 환산 확인이 필요하면 **환산 금액 다시 확인**을 눌러요. 가계부 반영 금액, 적용 환율과 실제 환율 기준일을 확인해요. 거래일 당일 환율이 없어 이전 공시 환율을 사용하면 경고가 표시돼요.
5. 수정한 내용은 **변경사항 적용**을 눌러 반영해요. **현재 원본과 입력값 확인 완료** 버튼이 표시되는 화면에서는 원본과 비교한 뒤 그 버튼을 먼저 눌러요. 입력을 다시 바꾸면 원본 확인이나 환산 확인을 다시 해야 할 수 있어요.
6. 저장할 후보를 선택하고 **선택한 N건 등록**을 눌러요. **등록 가능한 항목만 선택**으로 준비된 후보만 고를 수도 있어요.

사진에 **누락 영수증 영역 추가**가 표시되면, 분석이 놓친 영수증의 영역을 지정하거나 **전체 사진 사용**으로 후보를 추가할 수 있어요. 이 동작은 거래를 저장하지 않으므로 필요한 값을 입력하고 화면의 확인 절차를 마쳐 주세요. 해당 기능이 표시되지 않으면 놓친 영수증을 별도 사진으로 준비해 다시 분석해 주세요.

<Callout title="등록 버튼이 활성화되지 않을 때">
  선택한 후보의 **현재 등록 차단 사유**를 확인해 주세요. 필수값, 구매총액과 결제 합계, 유효한 환산 결과를 확인하고, 원본 확인 완료 항목이 표시되는 화면에서는 그 확인도 마쳐야 해요. 적용하지 않은 이름·금액 편집이 있다면 적용하거나 취소해 주세요. 등록에 실패하면 후보가 유지되므로 안내를 확인하고 다시 시도할 수 있어요.
</Callout>

## 완료 확인

등록 완료 안내와 거래 목록에서 결과를 확인해요. 일부 후보만 등록했다면 남은 후보의 상태와 차단 사유를 확인해 계속 검토해 주세요.
