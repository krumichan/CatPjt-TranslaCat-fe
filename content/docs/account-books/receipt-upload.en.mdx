---
title: Upload and analyze receipt photos
description: Select receipt photos and analyze them to prepare suggested transactions.
---

Start by [opening an account book](/en/docs/account-books/open).

## Follow these steps

1. Open **Add transaction → Analyze receipt (거래 등록 → 영수증 분석)**.
2. Choose an **Analysis method (분석 방식)** and select photos under **Receipt image (영수증 이미지)**. JPEG, PNG, and WebP are supported, with up to 10 images per selection.
3. Make sure each photo clearly shows no more than two receipts. Split three or more receipts into separate photos. Check that the date, store name, and total are sharp and fully visible.
4. Select **Analyze receipt (영수증 분석)**. Follow each photo's progress; you can retry or remove failed photos.

The upload area uses the available space in the window even before you choose photos. If the photo list or analysis button is lower down, **scroll inside the receipt analysis area**. This expanded area also shows progress while analysis is running, before results appear.

## Choose an analysis method

| Method | What it does |
| --- | --- |
| Fast AI Vision analysis (AI Vision 빠른 분석) | Analyzes photos with image AI. |
| OCR + AI to reduce cost (OCR + AI 비용 절약) | Combines text recognition and AI. |
| AI Vision first (recommended) (AI Vision 우선 (권장)) | Prioritizes image AI analysis. |
| OCR only (review required) (OCR만 사용 (검토 필요)) | Uses text recognition; compare the result carefully with the original. |

## Check the result

When analysis finishes and suggested transactions appear for each receipt, continue to review. Analysis alone does not save transactions.
