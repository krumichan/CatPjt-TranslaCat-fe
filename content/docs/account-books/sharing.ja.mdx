---
title: メンバーを招待して共同利用する
description: 家計簿にメンバーを招待し、参加状況とオーナー・メンバーの権限を確認します。
---

まず [家計簿を開く](/ja/docs/account-books/open)の手順で画面を開いてください。

## 順番に操作する

1. オーナーのアカウントで一覧の **人物アイコン** または詳細の **メンバー管理** を開きます。
2. 相手の **Public ID** を入力し、**招待** を押します。
3. 相手が上部の通知センターの **招待** から承認すると、メンバーとして参加します。

## 参加状況と権限を管理する

家計簿の作成者は **オーナー**、招待を承認して参加した人は **メンバー** と表示されます。

| 操作 | 利用方法 |
| --- | --- |
| メンバーを招待 | オーナーが一覧の人物アイコンまたは詳細の **メンバー管理** を開き、相手の **Public ID → 招待** を押します。 |
| 招待の承認・拒否 | 受信者が上部の通知センターの **招待** で家計簿への招待を確認し、承認または拒否します。 |
| 招待の取り消し・メンバーの削除 | オーナーが **メンバー管理** の招待中・現在のメンバーから操作します。 |
| 家計簿名・説明・カテゴリを修正 | オーナーが一覧カードの鉛筆アイコンから修正し、**登録** を押します。今月の目標金額を空欄にして保存すると、その月の目標が削除されます。 |
| 家計簿から退出 | メンバーが詳細の **家計簿から退出** を押し、確認します。退出後はその家計簿を閲覧できなくなります。 |
| 家計簿を削除 | オーナーが一覧カードのごみ箱アイコンを押し、確認します。 |

家計簿自体の修正・削除とメンバー管理はオーナーのみ利用できます。操作が表示されない場合は自分の役割を確認してください。Public IDの確認方法は [プロフィールと設定ガイド](/ja/docs/settings) で案内しています。

## 完了を確認する

招待後は招待中の一覧に相手が表示されたことを確認します。相手が承認すると現在のメンバー一覧で確認できます。
