먼저 [가계부 열기](/ko/docs/account-books/open)를 따라 화면을 열어 주세요.

## 순서대로 따라 하기

1. 오너 계정으로 가계부 목록의 **사람 아이콘** 또는 상세의 **멤버 관리**를 열어요.
2. 함께 사용할 사람의 **Public ID**를 입력하고 **초대**를 눌러요.
3. 상대가 상단 알림센터의 **초대**에서 수락하면 멤버로 참여해요.

## 참여 상태와 권한 관리하기

가계부를 만든 사람은 **오너**, 초대를 수락해 참여한 사람은 **멤버**로 표시돼요.

| 할 일 | 이용 방법 |
| --- | --- |
| 멤버 초대 | 오너가 목록의 사람 아이콘 또는 상세의 **멤버 관리**를 열고 상대의 **Public ID → 초대**를 눌러요. |
| 초대 수락·거절 | 받은 사람은 상단 알림센터의 **초대**에서 가계부 초대를 확인하고 수락하거나 거절해요. |
| 대기 중인 초대 취소·멤버 삭제 | 오너가 **멤버 관리**의 **초대 대기**, **현재 멤버**에서 처리해요. |
| 가계부명·설명·분류 수정 | 오너가 목록 카드의 연필 아이콘을 열어 수정하고 **등록**을 눌러요. 이번 달 목표 금액을 비운 채 저장하면 그달 목표가 삭제돼요. |
| 가계부에서 나가기 | 멤버가 상세의 **가계부 나가기**를 눌러 확인해요. 나가면 해당 가계부를 더 이상 볼 수 없어요. |
| 가계부 삭제 | 오너가 목록 카드의 휴지통 아이콘을 눌러 확인해요. |

오너만 가계부 자체의 수정·삭제와 멤버 관리를 할 수 있어요. 해당 버튼이 보이지 않으면 내 역할을 확인해 주세요. Public ID 확인 방법은 [프로필과 설정 가이드](/ko/docs/settings)에서 볼 수 있어요.

## 완료 확인

초대를 보냈다면 초대 대기에 상대가 표시되는지 확인해요. 상대가 수락하면 현재 멤버 목록에서 확인할 수 있어요.
