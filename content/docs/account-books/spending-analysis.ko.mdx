[가계부를 열고](/ko/docs/account-books/open) 상세 화면의 지출 차트 아래 **AI 지출 분석 → 분석 열기**를 눌러요. 이 기능은 이미 기록한 지출을 돌아보는 기능이에요. 영수증 사진을 거래로 등록하려면 [영수증 분석](/ko/docs/account-books/receipt-upload)을 이용해요.

## 기간을 정하고 시작하기

1. **AI 분석 기간**에서 **월별 / 분기별 / 반기별 / 연별 / 기간 지정** 중 하나를 골라요. 이 기간은 가계부 차트나 거래 내역에 적용한 기간과 별도로 바꿀 수 있어요.
2. **기간 지정**은 시작일과 종료일을 모두 포함해 달력 기준 최소 한 달을 선택해요. 선택 기간의 지출 합계와 거래 수를 확인해 주세요. 지출이 없는 기간은 분석할 수 없어요.
3. 필요하면 **추가로 알려주실 내용**에 구매 배경을 적어요. 예를 들어 외식이 주로 업무상 식사였다고 설명할 수 있어요. 최대 2,000자이며 비워 둬도 돼요.
4. **분석하기**를 눌러요. 선택 기간의 지출 내역과 작성한 설명이 AI 분석에 사용돼요. 이전 결과의 설명을 바꾼 경우에는 **다시 분석**을 눌러야 새 설명이 반영돼요.

## 진행 중인 분석과 완료 알림 확인하기

- **대기 중 / 분석 중**이면 창을 닫거나 다른 화면에 다녀와도 작업이 계속돼요. 가계부로 돌아와 **분석 열기**에서 진행 상태를 다시 확인할 수 있어요.
- 같은 가계부에 진행 중인 요청이 있으면 새 분석은 기다려 주세요. 창을 닫는 동작은 취소가 아니에요. 가계부 오너에게 **요청 취소**가 표시될 때 그 버튼으로 진행 중인 요청을 취소할 수 있어요.
- 완료되면 **요청자**에게 알림이 와요. 상단 알림 센터에서 해당 알림을 열거나, 분석 화면에 **결과 보기**가 나타나면 눌러 결과를 확인해요.

## 결과와 지난 분석 보기

1. **핵심 요약**을 읽고 개선안을 펼쳐요. 실제 지출에서 보인 점과 AI 의견, 개선 제안을 구분해 읽어요.
2. **근거 거래 보기**에서 분석 당시 거래와 금액을 확인해요. 근거 거래는 읽기 전용이므로 수정하려면 [거래 내역](/ko/docs/account-books/transactions)으로 돌아가요.
3. **예상 절약액**은 제안을 적용했다는 가정에서 계산한 값이에요. **계산에 사용한 가정 보기**를 열면 구매 감소와 대체 비용을 확인할 수 있어요. 산정 근거가 부족한 항목은 예상 합계에서 제외돼요.
4. **분석 이력**에서 저장한 결과를 선택하면 당시의 설명과 근거를 다시 볼 수 있어요. 같은 기간도 분석이 새로 완료되면 별도 기록으로 남고, 이력을 여는 것만으로 새 분석을 요청하지는 않아요.

<Callout title="결과가 일부 거래만 포함하거나 이전 거래 기준일 때">
  분석한 거래 수가 전체 거래 수보다 적다면 선택된 거래의 결과로 읽어 주세요. 거래를 나중에 수정했다면 기존 결과에는 변경 전 내역이 남아요. 최신 결과가 필요하면 다시 분석하고, 거래 변경 여부를 확인하지 못했다는 안내에는 **거래 상태 다시 확인**을 먼저 이용해요.
</Callout>

## 완료 확인

결과의 분석 기간과 분석 시각이 원하는 내용인지 확인해요. 개선안의 근거와 예상액 가정을 읽은 뒤, 결과는 분석 이력에서 다시 열 수 있어요.
