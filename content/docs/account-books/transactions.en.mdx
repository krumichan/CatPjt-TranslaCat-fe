---
title: Find, edit, or delete transactions
description: Search transactions by period and keyword, view their details, and edit or delete them.
---

Start by [opening an account book](/en/docs/account-books/open).

## Follow these steps

1. Scroll to the transactions near the bottom of the book details. Enter a search term and narrow the list with **All / Income / Expenses (전체 / 수입 / 지출)** and **All time (전체 기간)** or a specific month.
2. Choose **Cards / Table (카드 / 표)** and open a transaction's **Details (상세)**. You can check its memo and receipt payment/exchange rate records.

3. Select **Edit (수정)**, change the details, and select **Save (저장)**.
4. To remove a transaction, select **Delete (삭제)**, check the item in the confirmation dialog, and confirm.
5. If there are several pages, use **Previous / Next (이전 / 다음)** below the list.

Cards are easier to read on mobile. If a table is wider than the screen, scroll horizontally inside it.

<Callout title="Receipt transactions and recurring expense transactions">
  A transaction saved from a receipt keeps its exchange rate record, so you cannot edit its type, amount, or date. You can edit its name, store, category, and memo. If you delete a transaction generated from a recurring expense, that expense may appear as available to apply to the same month again.
</Callout>

## Check the result

After editing, check the updated values in the list and details. After deletion, check that the transaction no longer appears under the current search conditions.
