이 안내는 로그인 없이 읽을 수 있어요. 실제 기능은 [로그인](/ko/login) 후 내 계정에서 이용해 주세요.

## 친구와 1:1 채팅 열기

1. [친구 목록](/ko/chat?tab=friends)에서 대화할 친구를 찾아요.
2. **1:1 채팅**을 눌러요. 검색 결과에서 이미 친구인 사용자는 **1:1 채팅 시작**으로 열 수도 있어요.
3. 방 이름과 상대 프로필을 확인한 뒤 대화를 시작해요.

아직 친구가 아니라면 먼저 [친구 추가하기](/ko/docs/chat/friends)를 진행해요.

## 그룹 채팅 만들고 멤버 초대하기

### 친구 목록에서 만들기

1. **친구** 탭에서 **그룹 선택**을 눌러요.
2. 함께 대화할 친구를 한 명 이상 선택하고 **그룹 만들기**를 눌러요.
3. 선택한 친구를 확인하고 **그룹명**을 입력해요. **설명**은 선택 사항이에요.
4. **그룹 채팅 만들기**를 누르면 새 방으로 이동해요.

선택을 바꾸려면 **친구 선택 변경**, 전부 해제하려면 친구 목록의 **선택 해제**를 사용해요. 차단 상태나 친구 관계가 바뀐 사용자는 최종 확인에서 제외될 수 있어요.

### 기존 방에서 초대하기

초대가 가능한 방에서는 **⋮ 채팅방 메뉴 → 멤버 초대**를 열어요. 친구 목록에서 선택하거나 **TranslaCat ID 직접 입력 → 추가**로 초대 대상을 넣을 수 있어요.

| 현재 방 | 동작 |
| --- | --- |
| 친구와의 1:1 채팅 | 그룹 이름을 입력하고 **그룹 만들기**를 눌러요. 기존 상대와 초대 대상을 포함하는 **새 그룹방**을 만들며, 기존 1:1 방과 메시지는 그대로 남아요. 메시지를 새 그룹에 복사하지 않아요. |
| 일반 그룹 채팅 | 방장 또는 방 관리자인 경우 **초대하기**로 멤버를 추가할 수 있어요. |

자기 자신, 이미 참여 중인 사용자, 차단 관계인 사용자는 초대할 수 없어요. 방의 종류와 내 역할에 따라 초대 버튼이 나타나지 않을 수 있어요.

## 완료 확인

새 그룹방으로 이동하고 의도한 방 이름과 멤버가 보이면 완료예요. 기존 그룹에 초대한 경우에는 멤버 목록에서 추가된 사용자를 확인해요.
