## Add a friend and start a direct chat

1. In the [Friends tab](/en/chat?tab=friends), click **Find friends (친구 찾기)**.
2. Enter the other person's **TranslaCat ID** and click **Search (검색)**. Search uses the unique ID, not a nickname.
3. Check the person in the results and click **Send friend request (친구 요청 보내기)**.
4. After they accept, click **1:1 chat (1:1 채팅)** in the friends list. For a search result that is already a friend, **Start 1:1 chat** opens it directly.

Manage received requests under **Notifications (bell icon) → Invitations (초대)** with **Accept / Decline**. You can **Cancel** a pending request you sent from the same place. After sending a request, wait for the other person's response.

Find and copy your own TranslaCat ID in [My profile](/en/settings/profile). See [Profile and settings](/en/docs/settings) for more details.

## Manage friends

- Filter the friends list by **nickname or TranslaCat ID**.
- Select a friend's profile to preview their status message and start a direct chat.
- **Friend menu → Remove friend** ends the friend relationship. Existing chat rooms remain.
- **Block** hides the user from your friends list and restricts friend requests, starting direct chats, and group selection. It does not automatically delete existing chat rooms.
- Use **Blocked users → Unblock** to remove a block. If the friend relationship was also removed, you may need to send a new friend request.

## Check that you are done

Sending a request does not immediately make you friends. Check that the user appears in your friends list after acceptance. Check the list state after removing, blocking, or unblocking someone.
