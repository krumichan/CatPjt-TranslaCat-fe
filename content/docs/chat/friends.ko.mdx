## 친구 추가하고 1:1 채팅 시작하기

1. [친구 탭](/ko/chat?tab=friends)에서 **친구 찾기**를 눌러요.
2. 상대방이 알려준 **TranslaCat ID**를 입력하고 **검색**을 눌러요. 닉네임이 아닌 고유 ID로 사용자를 찾아요.
3. 결과에서 상대방을 확인하고 **친구 요청 보내기**를 눌러요.
4. 상대방이 요청을 수락한 뒤 친구 목록에서 **1:1 채팅**을 눌러요. 이미 친구인 검색 결과에서는 **1:1 채팅 시작**으로 바로 열 수 있어요.

받은 요청은 상단 **알림(종 아이콘) → 초대**에서 **수락 / 거절**할 수 있어요. 보낸 요청이 대기 중이면 같은 곳에서 **취소**할 수 있어요. 친구 요청을 보낸 상태라면 상대방의 응답을 기다려 주세요.

내 TranslaCat ID는 [내 프로필](/ko/settings/profile)에서 확인하고 복사할 수 있어요. 자세한 내용은 [프로필·설정 가이드](/ko/docs/settings)를 참고해 주세요.

### 친구 관리하기

- 친구 목록에서는 **닉네임 또는 TranslaCat ID**로 필터링할 수 있어요.
- 친구 프로필을 누르면 미리보기를 열어 상태 메시지를 확인하고 1:1 채팅을 시작할 수 있어요.
- **친구 메뉴 → 친구 삭제**는 친구 관계를 해제해요. 기존 채팅방은 삭제되지 않아요.
- **차단**하면 친구 목록에서 숨겨지며 친구 요청, 1:1 채팅 시작, 그룹 선택이 제한돼요. 기존 채팅방이 자동으로 삭제되는 것은 아니에요.
- **차단 목록 → 차단 해제**로 해제할 수 있어요. 친구 관계도 삭제된 상태라면 다시 친구 요청이 필요할 수 있어요.

## 완료 확인

요청을 보낸 것만으로 친구가 되지는 않아요. 상대방이 수락한 뒤 친구 목록에 표시되는지 확인해 주세요. 삭제·차단·해제 후에는 목록 상태를 확인해요.
