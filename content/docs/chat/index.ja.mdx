友達との1:1、グループ、OPENルームで会話できます。メッセージの原文と訳文を確認しながら、異なる言語で話してみましょう。

<Callout title="ログインして利用してください">
  このガイドは公開されていますが、チャット、友だち検索、OPENチャットへの参加にはログインが必要です。説明画面のアカウントと会話は、使い方を示すサンプルデータです。
</Callout>

## 目的に合う操作を選ぶ

初めての場合は、**チャットを開く → 友達追加 → 1:1・グループで会話 → メッセージと翻訳を設定**の順に進めましょう。友達関係なしで参加する場合はOPENチャットの案内を開いてください。

## 困ったときは

| 状況 | 確認すること |
| --- | --- |
| 友達が見つからない | ニックネームではなく、相手の正確なTranslaCat IDを入力したか確認します。 |
| 1:1チャットを始められない | 友だちリクエストが承認済みか、ブロック関係がないかを確認します。 |
| メッセージを送れない | 接続と参加状態を確認します。終了済み・強制退出済みのOPENルームには送信できません。 |
| 翻訳が表示されない | 自分の言語設定の受信翻訳言語と翻訳表示を確認します。失敗した訳文は再翻訳できます。 |
| 招待・AI管理ボタンがない | ルームの種類と自分の役割によって使えるメニューが変わります。 |
| AIを呼んでも応答しない | 実際のAIニックネームで呼んだか、呼び出し権限や利用制限を確認します。 |
| 一覧や以前のメッセージを読み込めない | エラー欄の**再試行**を押し、ネットワークとログイン状態を確認します。 |

解決しない場合は[サポートガイド](/ja/docs/support)を参考に、ルームの種類と表示されたエラーをお知らせください。
