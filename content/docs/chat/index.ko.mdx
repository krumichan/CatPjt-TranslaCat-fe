친구와 1:1로 이야기하거나 그룹·OPEN 채팅방에 참여할 수 있어요. 메시지의 원문과 번역문을 함께 보며 다른 언어로 대화해 보세요.

<Callout title="로그인 후 이용해 주세요">
  이 가이드는 공개되어 있지만 채팅, 친구 찾기, OPEN 채팅 참여에는 로그인이 필요해요. 안내 화면의 계정과 대화는 사용법을 설명하기 위한 예시 데이터예요.
</Callout>

## 문제가 생겼을 때

| 상황 | 먼저 확인할 내용 |
| --- | --- |
| 친구를 찾지 못해요 | 닉네임 대신 상대방의 정확한 TranslaCat ID를 입력했는지 확인해요. |
| 1:1 채팅을 시작할 수 없어요 | 친구 요청이 수락되었는지, 차단 관계가 아닌지 확인해요. |
| 메시지가 전송되지 않아요 | 연결 상태와 방의 참여 상태를 확인해요. 종료되거나 강제 퇴장된 OPEN 방에서는 전송할 수 없어요. |
| 번역문이 안 보여요 | 내 언어 설정의 수신 번역 언어와 번역 표시를 확인해요. 실패한 번역은 재번역을 눌러요. |
| 초대·AI 관리 버튼이 없어요 | 방의 종류와 내 역할에 따라 사용할 수 있는 메뉴가 달라져요. |
| AI를 불러도 답이 없어요 | 실제 AI 닉네임으로 멘션했는지, 방의 호출 권한과 사용 제한에 걸리지 않았는지 확인해요. |
| 목록이나 이전 메시지를 불러오지 못해요 | 오류 영역의 **다시 시도**를 누르고 네트워크·로그인 상태를 확인해요. |

계속 문제가 생기면 [고객센터 가이드](/ko/docs/support)를 참고해 방 종류와 표시된 오류를 알려 주세요.
