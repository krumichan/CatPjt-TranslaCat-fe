You can read these instructions without signing in. To use the feature, [sign in](/en/login) with your own account. Service links open the English interface. Screenshots show the Korean interface; Korean labels in parentheses help you compare the two.

## Send a message and read its translation

1. Open a room you have joined.
2. Enter text in **Type a message (메시지를 입력하세요)** at the bottom.
3. Click the **Send button (paper plane)** on the right. On PC, **Enter** sends and **Shift + Enter** starts a new line. Mobile also provides the on-screen send button.
4. Check the translated text and language label below the message. If it says **Translating**, wait for completion.

If sending fails, your input remains. Check the connection and notice, then send again. A failed translation offers **Retranslate** and **Refresh**. Retranslate requests the translation again; Refresh fetches its latest result.

Scroll upward in the message list to read older conversation. Use **Latest messages** to return to recent messages. You can also see unread counts and a **Unread from here** marker.

## Set your translation languages

1. Open **My language settings (내 언어 설정)** at the top of the room. On mobile this is the **language icon**.
2. Set **Original text language** to the language you will type, and **Incoming translation language** to the language you want to read.
3. Choose **Show original / Show translation** as you prefer, then click **Save (저장)**.

Korean, Japanese, and **English** are available. **My language settings for this room** apply only to your view in the current room. They do not change another member's settings or another room. Set starting defaults for other rooms under [Settings → Chat language](/en/settings/chat). Saved room-specific values take precedence over personal defaults.

Even with original display off, the original can remain visible when a translation is not ready or has failed, so the message content is still available. Keep both original and translation visible when checking whether AI translation preserves the meaning.

## Check that you are done

Check that your sent message appears. When translation finishes, read the translation in your chosen language. Reopen language settings to check that the saved choices remain.
