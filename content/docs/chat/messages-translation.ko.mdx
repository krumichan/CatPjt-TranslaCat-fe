## 메시지 보내고 번역 읽기

1. 참여 중인 방을 열어요.
2. 아래 **메시지를 입력하세요** 입력란에 내용을 적어요.
3. 오른쪽 **보내기(종이비행기 모양) 버튼**을 누르면 전송돼요. PC에서는 **Enter**로 전송하고 **Shift + Enter**로 줄을 바꿀 수 있어요. 모바일에서도 화면의 전송 버튼을 사용할 수 있어요.
4. 메시지 아래의 번역문과 언어 표시를 함께 확인해요. **번역 중**이라면 완료될 때까지 기다려 주세요.

전송 실패 시 입력 내용은 남아 있으므로 연결 상태와 안내를 확인한 뒤 다시 전송할 수 있어요. 번역에 실패한 메시지에는 **재번역**과 **새로고침**이 표시돼요. 재번역은 해당 메시지의 번역을 다시 요청하고, 새로고침은 최신 결과를 다시 불러와요.

이전 대화는 메시지 목록을 위로 스크롤해 확인해요. 이전 내역을 보다가 최근 대화로 돌아가려면 **최신 메시지로**를 눌러요. 메시지의 읽지 않은 인원과 **여기부터 안 읽음** 표시도 확인할 수 있어요.

## 내 번역 언어 설정하기

1. 방 상단의 **내 언어 설정**을 열어요. 모바일에서는 **언어 아이콘**이에요.
2. **원문 기준 언어**에 내가 입력할 언어를, **수신 번역 언어**에 번역문을 읽고 싶은 언어를 선택해요.
3. **원문 표시 / 번역 표시**를 원하는 방식으로 선택하고 **저장**을 눌러요.

한국어·일본어·영어를 선택할 수 있어요. **이 채팅방에서의 내 언어 설정**은 현재 방에만 적용되고 다른 멤버나 다른 방의 설정을 바꾸지 않아요. 여러 방에서 처음 사용할 기본값은 [설정 → 채팅 언어](/ko/settings/chat)에서 정해요. 방별로 저장한 값은 개인 기본값보다 우선해요.

원문 표시를 꺼도 번역이 아직 없거나 실패한 메시지는 내용을 잃지 않도록 원문이 보일 수 있어요. AI 번역이 원래 뜻과 다른지 확인하려면 원문과 번역을 함께 켜 두세요.

## PC·모바일에서 조작하기

  </Tab>

## 완료 확인

보낸 메시지가 목록에 나타나고 번역이 끝나면 선택한 언어의 번역문을 확인해요. 언어 설정은 저장 후 다시 열어 선택이 유지되는지 확인할 수 있어요.
