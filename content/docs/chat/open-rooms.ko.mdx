## OPEN 채팅 참여하기

OPEN 채팅은 친구 관계 없이 방별 프로필로 참여하는 대화예요.

1. 채팅 화면의 **OPEN 채팅 둘러보기**를 눌러요.
2. 방 이름 또는 설명으로 검색하거나 공개방 목록을 살펴봐요. 검색어를 비우면 전체 공개방 목록으로 돌아가요.
3. 원하는 방의 **상세 보기**를 열고 설명, 방장, 인원, 참여 가능 여부를 확인해요.
4. **참여하기**를 눌러 **방별 닉네임**과 원하는 프로필 이미지를 설정해요.
5. 참여 프로필을 확인하고 **이 프로필로 참여**를 눌러요. 이미 참여한 방은 **채팅방 입장**으로 바로 이동해요.

방별 프로필은 일반 프로필과 별개예요. OPEN 화면에는 일반 프로필, TranslaCat ID, 친구 관계가 표시되지 않아요. 닉네임이 같더라도 고유한 **멤버 코드**로 구분하며, 멤버 코드는 바꿀 수 없어요.

프로필 이미지는 **JPG·PNG·WEBP, 5MB 이하**를 선택할 수 있어요. 이미지를 고르지 않으면 기본 OPEN 아바타가 표시돼요. 참여는 완료됐지만 이미지 처리만 실패했다면 **이미지 처리 다시 시도**를 사용해 주세요.

정원이 찼거나 방이 종료되었거나 참여가 제한된 경우에는 참여할 수 없어요. **링크 공개** 방은 목록·검색에 나타나지 않아요. 공유받은 방 링크나 받은 초대의 **방 미리보기**로 열어요.

## 받은 초대로 방 열기

1. [채팅](/ko/chat) 위쪽에서 [**OPEN 채팅 초대**](/ko/chat/open/invitations)를 눌러요. 상단 알림센터의 OPEN 초대 알림에서도 방 미리보기를 열 수 있어요.
2. 방 이름과 초대한 사람의 방별 닉네임을 확인한 뒤 **방 미리보기**를 눌러요. 지금 확인만 하려면 **읽음 처리**를 눌러요.
3. 참여하려면 미리보기 화면에서 **참여하기**를 누르고 방별 프로필을 확인해요. 초대나 미리보기만으로 자동 참여하지는 않아요.

### 내 OPEN 프로필과 나가기

- 방 안의 **⋮ 메뉴 → 내 OPEN 프로필 수정**에서 방별 닉네임과 이미지를 바꾸고 **변경사항 저장**을 눌러요. 일반 프로필에는 영향을 주지 않아요.
- 멤버 프로필에서 멤버 코드를 확인하고 복사할 수 있어요.
- **OPEN 방 나가기**를 선택하면 확인창이 열려요. 나갔다가 다시 참여할 때 프로필과 멤버 코드는 유지되지만 **재참여 이전 메시지는 다시 볼 수 없어요**.
- 방장이 방을 종료하면 메시지를 더 이상 보낼 수 없어요. 강제 퇴장된 방은 차단이 해제되기 전까지 다시 참여할 수 없어요.

## 완료 확인

참여한 방의 대화 화면이 열리고 내 방별 프로필이 보이면 완료예요. 프로필을 바꿨다면 저장 후 다시 열어 변경 내용을 확인해요.
