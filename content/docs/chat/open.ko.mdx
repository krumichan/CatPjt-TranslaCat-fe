이 안내는 로그인 없이 읽을 수 있어요. 실제 기능은 [로그인](/ko/login) 후 내 계정에서 이용해 주세요.

## 채팅 열기

<Tabs items={["PC", "모바일"]} groupId="chat-device-ko">
  <Tab value="PC">
    1. 왼쪽 메뉴의 **채팅**을 클릭하거나 [채팅 화면](/ko/chat)을 열어요.
    2. **채팅** 탭에서 참여 중인 방을, **친구** 탭에서 친구 목록을 확인해요.
    3. 방 안에서는 상단의 **내 언어 설정**으로 번역 언어를, **⋮ 버튼**으로 채팅방 메뉴를 열어요.

  <Tab value="모바일">
    1. 왼쪽 위 **☰ 메뉴 → 채팅**을 누르거나 [채팅 화면](/ko/chat)을 열어요.
    2. **채팅 / 친구** 탭을 눌러 전환하고, 목록을 아래로 스크롤해 원하는 방이나 친구를 찾아요.
    3. 방 안의 좁은 화면에서는 **내 언어 설정** 글자가 숨겨지고 **언어 아이콘**만 보여요. 상단 오른쪽의 언어 아이콘을 누르면 같은 설정이 열려요. 바로 옆 **⋮ 버튼**은 채팅방 메뉴예요.

메뉴와 버튼의 모양은 화면 너비에 따라 달라져요. PC 창이 좁으면 모바일 안내를 참고해 주세요.

## 완료 확인

채팅 / 친구 탭과 OPEN 채팅 진입 버튼을 찾을 수 있으면 준비가 끝났어요. 기존 대화는 방 목록에서 원하는 방을 눌러 이어갈 수 있어요.
