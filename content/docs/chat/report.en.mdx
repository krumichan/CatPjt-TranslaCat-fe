title: Report a chat message or participant
description: Choose a message or participant in a chat and submit a report to the moderation team.
---

You can read this guide without signing in. To submit a report, sign in and open the [chat room](/en/chat) where the issue occurred.

## Submit a report

1. Below the other person's message, select **Report message** or **Report participant**. The participant option appears on messages from people you can report.
2. Choose a **Reason** and add **Additional details** if needed. Leave out sensitive information such as passwords and verification codes.
3. Read the evidence notice, agree to it, and select **Submit report**. A confirmation and report number appear once the report is received.

The moderation team reviews reports. Submitting a report does not automatically suspend an account. Evidence for moderation is kept for 90 days from submission. The actual account information of OPEN chat participants is not displayed.

## If the report option or confirmation is missing

- Your own messages, hidden or deleted messages, system messages, and messages from deleted accounts do not show report options.
- If receipt could not be confirmed, choose **Resend the same report**. It uses the same request to prevent a duplicate.
- For a service problem or account question, use [a private support inquiry](/en/docs/support/inquiries).
