TranslaCat에서 영어로 대화를 번역하고, 영어를 공부하고, 이용 권한이 있는 소설을 영어로 읽을 수 있어요. **각 기능의 언어는 따로 선택**하므로, 지금 사용하려는 기능의 설정을 확인해 주세요.

<Callout title="가이드 언어와 서비스 언어를 구분해 주세요">
  가이드는 한국어·일본어·영어로 읽을 수 있어요. 서비스의 화면 언어도 한국어·일본어·영어와 학습 모드 중에서 선택할 수 있어요. 서비스의 언어 버튼에서 **EN**을 고르면 영어 메뉴로 바뀌며, 가이드 언어와 학습·번역 대상 언어는 각각 별도로 선택해요. 이 가이드는 로그인 없이 읽을 수 있지만 기능 이용에는 로그인이 필요하고, 소설 번역은 ADMIN 계정만 이용할 수 있어요.
</Callout>

## 어디에서 영어를 선택하나요?

| 하려는 일 | 영어를 선택하는 곳 | 자세한 안내 |
| --- | --- | --- |
| 말소리를 영어로 번역하거나 영어 발화를 번역하기 | 음성 번역의 입력 언어·번역 언어 | [음성 번역 언어와 저장](/ko/docs/voice/languages-storage) |
| 채팅을 영어로 읽고 쓰기 | 채팅방의 내 언어 설정 | [메시지와 번역 설정](/ko/docs/chat/messages-translation) |
| 채팅의 기본 언어·AI 대화 언어 정하기 | 프로필의 채팅 설정·방의 AI 설정 | [채팅 기본값](/ko/docs/settings/chat-defaults) · [AI 멤버](/ko/docs/chat/ai-members) |
| 영어로 공부하기 | 학습 설정의 원문·학습·설명 언어 | [영어로 학습 시작하기](/ko/docs/language-learning/english) |
| 일본어 소설을 영어로 읽고 듣기 | 관리자용 소설의 번역 언어 | 아래의 **관리자용 소설 영어 번역** |

## 음성 번역: 한국어·일본어·영어 사이에서

세 언어 사이의 **여섯 방향**을 이용할 수 있어요: 한국어→일본어, 일본어→한국어, 한국어→영어, 영어→한국어, 일본어→영어, 영어→일본어예요.

1. [음성 번역](/ko/voice)에서 입력 방식을 고른 뒤 **입력 언어**를 자동 감지하거나 직접 지정해요. 직접 지정할 때는 실제로 말하는 언어를 골라요.
2. **번역 언어**에는 결과를 읽고 싶은 언어를 골라요. 한국어 발화를 영어로 읽으려면 입력은 한국어, 번역은 영어로 설정해요.
3. 세션을 시작하고 원문·번역문과 연결 상태를 확인해요. 회의 모드라면 내 음성과 상대방 음성의 입력 언어를 각각 확인해요.

발화와 번역 언어가 같으면 번역이 필요하지 않아 원문만 표시될 수 있어요. 마이크·시스템 오디오와 PC·모바일 차이는 [입력 방식](/ko/docs/voice/input-modes), 시작과 종료는 [실시간 번역](/ko/docs/voice/live-translation)을 참고해 주세요.

## 채팅: 방 설정과 기본값을 확인해요

채팅방 위쪽의 **내 언어 설정**에서 **원문 언어**와 **수신 번역 언어**를 선택하고 저장해요. 모바일에서는 같은 설정을 언어 아이콘으로 열어요. 영어로 입력할 때는 원문 언어를 영어로, 상대방의 말을 영어로 읽으려면 수신 번역 언어를 영어로 골라요.

방별 설정은 내 화면에 적용돼요. 다른 방에서 시작할 기본값은 [프로필의 채팅 언어 설정](/ko/docs/settings/chat-defaults)에서 정하며, 저장된 방별 설정이 있으면 그 값이 우선해요. 방장·방 관리자가 설정하는 **AI 멤버의 언어**도 별도이므로 [AI 멤버 가이드](/ko/docs/chat/ai-members)를 확인해 주세요.

## 영어 학습: 적용일과 현재 언어쌍을 확인해요

[영어 학습 설정](/ko/docs/language-learning/english)에서 원문 언어와 다른 학습 언어를 선택해요. 영어를 공부하려면 **학습 언어를 영어**로 정하고 설명·피드백 언어는 읽기 편한 언어로 선택하면 돼요. 최초 설정은 즉시, 이후 언어·시간대·하루 목표 변경은 현재 학습 시간대 기준 다음 학습일부터 적용돼요.

레벨 테스트와 [쓰기](/ko/docs/language-learning/writing)·[말하기](/ko/docs/language-learning/speaking)·[듣기](/ko/docs/language-learning/listening)·[읽기](/ko/docs/language-learning/reading)를 현재 언어로 이용해요. 웹 AI를 쓰면 [계획의 언어](/ko/docs/language-learning/web-ai)도 확인해 주세요. 한국어→일본어 전용 QA 작문은 기존 전용 기능이며 영어 학습에는 일반 작문이 제공돼요.

현재 점수와 프로필은 원문/학습 언어쌍을 기준으로 확인하지만, **전체 이력과 연속 학습일은 여러 언어의 활동을 보존**해요. 공식 레벨 테스트의 하루 완료 한도는 언어 전체에 공통이에요. Base Level과 Band는 앱 내부 학습 기준이며 CEFR 등급이나 공인 시험 성적이 아니에요.

## 관리자용 소설 영어 번역

<Callout title="이용 가능한 계정과 작품">
  이 기능은 **ADMIN 계정**의 소설 번역 기능이에요. 영어 번역은 **소설가가 되자(Syosetu)** 작품에서 지원하며, 카쿠요무에는 영어 번역 선택지가 제공되지 않아요. 일반 계정에서는 소설 메뉴나 화면을 이용할 수 없어요.
</Callout>

1. ADMIN 계정으로 로그인한 뒤 [소설 번역](/ko/novel)에서 **소설가가 되자**를 선택하고 검색 또는 순위 목록을 열어요.
2. 목록의 **번역 언어 → 영어**를 선택해요. 작품·목차에서 읽을 회차를 열고, 본문 위쪽에서도 **번역 언어**가 영어인지 확인해요. 단편은 바로 본문으로 열릴 수 있어요.
3. 번역이 필요하면 **전체 번역 시작**을 눌러요. 준비된 **영어 번역**을 읽고, 실패한 부분은 화면에 제공되는 재번역 버튼을 이용해요.
4. 화면 아래 조작바의 **PREV / NEXT**로 회차를 이동해요. **OPEN → LIST**로 목차에 돌아갈 수 있어요. 이 이동과 새로고침에서도 선택한 영어 번역을 유지해요.
5. **OPEN**을 펼쳐 **번역문 전체 읽기**를 누르면 준비된 영어 번역을 들을 수 있어요. **원문 전체 읽기**는 일본어예요. 일시정지·재개·정지와 낭독 속도를 조절할 수 있어요.
6. 나중에 사이드 메뉴의 **최근 활동**에서 같은 작품을 열면 마지막 영어 선택을 이어갈 수 있어요.

작품 제목·소개나 회차 제목은 영어 번역이 준비되지 않았다면 **일본어 원문으로 표시될 수 있어요**. 본문을 영어로 읽는다고 모든 제목이 자동으로 영어가 되는 것은 아니에요. 낭독은 현재 회차 본문을 대상으로 하며 제목·서문·후기는 포함하지 않아요.
