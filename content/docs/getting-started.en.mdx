Follow these steps if you are new to TranslaCat. Already have an account? Skip to [signing in](#sign-in).

Service links open the **English interface**. Screenshots show the **Korean interface**; Korean labels in parentheses help you match the pictured controls to the English instructions. Select a screenshot to enlarge it.

Registration and sign-in work the same way on PC and mobile. For language selection and navigation, choose the **PC / Mobile** tab that matches your screen. The selected tab is shared between the instructions on this page.

Menu placement follows the window width. If you see **☰** on a narrow desktop window or tablet, use the mobile instructions. Some widths show both the menu button and a **Language** button displaying a flag or **EN**.

## Create an account

Have access to the inbox for the email address you want to register.

### Verify your email

1. Open [registration in English](/en/register).
2. Enter your **Email (이메일)** and select **Send verification code (인증 코드 보내기)**.
3. Enter the **six-digit code** from the email and select **Verify email (이메일 인증하기)**.

If the message does not arrive, check the address and your spam folder. If the code expires, follow the resend timer and select **Resend verification code (인증 코드 다시 보내기)**. Use the newest code.

### Enter account details

After verification, the remaining fields appear.

1. Enter your **Password (비밀번호)**, **Confirm password (비밀번호 확인)**, **Nickname (닉네임)** and **Date of birth (생년월일)**. The password must have at least eight characters and meet the requirements shown below the field.
2. Select **Create account (계정 만들기)**. Successful registration takes you to sign-in.

## Sign in

### Use email and password

1. Open [sign-in in English](/en/login).
2. Enter the email address and password you registered.
3. Select **Log in (로그인)** to open the service selection screen.

### Continue with Google

Select the **Google icon** and follow Google's account selection screen.

If asked to link Google to an existing email account, sign in with your existing email and password first. Then follow [Account and login settings](/en/docs/settings/account-login) to link Google from your account.

## Change the interface language

The service offers **Korean, Japanese, English, and Learning mode** interfaces. Open the **Language** menu and choose **EN (English)** to use English menus and buttons. Study and translation languages are separate settings; choosing the English interface does not change those targets.

## Troubleshooting

| Situation | What to check |
| --- | --- |
| The verification email has not arrived | Check the address and spam folder, then follow the resend instructions. |
| The code has expired | Request a new code and use the most recent message. |
| Sign-in fails | Check the registered email and password. If you used Google, use the Google icon again. |
| The email is already registered | Sign in using your existing method. Add another sign-in method from Account and login settings. |
| A request could not be processed | Follow the displayed message and try again later. |

After signing in, use **1:1 inquiries → Contact support** in [Support](/en/docs/support/inquiries) if you need help. Include the screen, the action you attempted and the exact message you saw.
