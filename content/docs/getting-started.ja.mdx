初めてTranslaCatを使う方は、以下の手順に沿って進めてください。アカウントをお持ちの方は、[ログインする](#ログインする)から始められます。

各手順の実際の画面を見ながら進めましょう。画像を押すと拡大できます。

新規登録とログインの手順は、PCでもスマートフォンでも同じです。画面の構成が異なる**言語の変更**と**サービス間の移動**は、以下の **PC / スマートフォン** タブを選んでお読みください。一方で選んだタブは、もう一方の案内にも反映されます。

メニューの構成は画面の幅によって変わります。PCのウィンドウを狭くした場合やタブレットで、左上に **☰ メニューボタン**が表示される場合は、スマートフォンの案内をご覧ください。画面の幅によっては、メニューボタンと上部の国旗ボタンが両方表示されることもあります。

<Callout title="どなたでも読めるガイドです">
  このページはログインせずに開いたり共有したりできます。登録やログインの途中でも、いつでもご確認ください。
</Callout>

## アカウントを作成する

メールで登録する場合は、メールを受信できるアドレスをご用意ください。

### メールアドレスを確認する

1. [新規登録ページ](/ja/register)を開きます。
2. **メールアドレス**を入力し、**確認コードを送信**を押します。
3. メールに届いた**6桁の確認コード**を入力し、**メールアドレスを確認**を押します。

確認メールが見つからない場合は、メールアドレスと迷惑メールフォルダーをご確認ください。コードの有効期限が切れた場合は、画面に表示される再送信までの時間を確認し、**確認コードを再送信**から新しいコードを取得してください。

### アカウント情報を入力する

メールアドレスの確認が完了すると、残りの入力欄が表示されます。

1. **パスワード**、**パスワードの確認**、**ニックネーム**、**生年月日**を入力します。パスワードは8文字以上で、入力欄の下にある案内に沿って設定してください。
2. **アカウントを作成**を押します。登録が完了すると、ログイン画面に移動します。

## ログインする

### メールアドレスとパスワードでログイン

1. [ログインページ](/ja/login)を開きます。
2. 登録したメールアドレスとパスワードを入力します。
3. **ログイン**を押すと、すべてのサービスを選べる画面に移動します。

### Googleで続ける

ログイン画面の**Googleアイコンのボタン**を押し、Googleの画面に従ってアカウントを選んでください。

既存のメールアカウントにGoogleを連携するよう案内が表示された場合は、まず登録済みのメールアドレスとパスワードでログインしてください。ログイン後、[設定のアカウントとログイン](/ja/settings/account)から案内に沿ってGoogleを連携できます。

## うまくいかないときは

| 状況 | まずご確認ください |
| --- | --- |
| 確認メールが届かない | メールアドレスと迷惑メールフォルダーを確認し、画面の再送信の案内に従ってください。 |
| 確認コードの有効期限が切れた | コードを再送信し、最後に届いたコードで確認してください。 |
| ログインできない | 登録したメールアドレスとパスワードを確認してください。Googleをご利用の場合は、Googleボタンから再度お試しください。 |
| 登録済みのメールアドレスと表示される | 既存の方法でログインしてください。ログイン方法の追加は、設定の**アカウントとログイン**から行えます。 |
| リクエストを処理できないと表示される | 画面の案内を確認し、しばらくしてから再度お試しください。 |

ログイン後もお困りの場合は、[サポート](/ja/support)の**お問い合わせ → 問い合わせる**から状況をお知らせください。どの画面で何をしたときに問題が起きたか、表示されたメッセージとあわせて記載すると、状況を確認しやすくなります。

ほかの内容を見る場合は、[ガイドホーム](/ja/docs)に戻ってください。
