TranslaCat이 처음이라면 아래 순서대로 따라와 주세요. 이미 계정이 있다면 [로그인하기](#로그인하기)부터 시작하면 돼요.

각 단계의 실제 화면을 함께 보며 따라 해 보세요. 이미지를 누르면 크게 볼 수 있어요.

회원가입과 로그인 절차는 PC와 모바일에서 같아요. 화면 구성이 다른 **언어 변경**과 **서비스 이동**은 아래의 **PC / 모바일** 탭에서 사용 중인 화면에 맞춰 읽어 주세요. 한 곳에서 고른 탭은 다른 안내에도 함께 적용돼요.

메뉴 구성은 화면 너비에 따라 달라져요. PC 창을 좁게 쓰거나 태블릿에서 왼쪽 위 **☰ 메뉴 버튼**이 보이면 모바일 안내를 참고해 주세요. 화면이 조금 넓으면 메뉴 버튼과 상단 국기 버튼이 함께 보일 수도 있어요.

<Callout title="가이드는 누구나 읽을 수 있어요">
  이 페이지는 로그인 없이 열고 공유할 수 있어요. 가입이나 로그인 중에도 다시 찾아와 확인해 보세요.
</Callout>

## 계정 만들기

이메일로 가입할 때는 메일을 받을 수 있는 이메일 주소를 준비해 주세요.

### 이메일 인증하기

1. [회원가입 페이지](/ko/register)를 열어요.
2. **이메일**을 입력하고 **인증 코드 보내기**를 눌러요.
3. 받은 메일의 **6자리 인증 코드**를 입력한 뒤 **이메일 인증하기**를 눌러요.

인증 메일이 보이지 않으면 이메일 주소와 스팸함을 확인해 주세요. 코드가 만료되었다면 화면에 표시되는 재전송 가능 시간을 확인한 뒤 **인증 코드 다시 보내기**를 눌러 새 코드로 인증해 주세요.

### 계정 정보 입력하기

이메일 인증을 마치면 나머지 입력란이 나타나요.

1. **비밀번호**, **비밀번호 확인**, **닉네임**, **생년월일**을 입력해요. 비밀번호는 8자 이상이며, 입력란 아래 안내에 맞춰 정해 주세요.
2. **계정 만들기**를 눌러요. 가입이 완료되면 로그인 화면으로 이동해요.

## 로그인하기

### 이메일과 비밀번호로 로그인

1. [로그인 페이지](/ko/login)를 열어요.
2. 가입한 이메일과 비밀번호를 입력해요.
3. **로그인**을 누르면 전체 서비스 화면으로 이동해요.

### Google로 계속하기

로그인 화면의 **Google 아이콘 버튼**을 누르고, Google 화면의 안내에 따라 계정을 선택해 주세요.

기존 이메일 계정에 Google을 연결하라는 안내가 나오면, 먼저 기존 이메일과 비밀번호로 로그인해 주세요. 로그인 후 [설정의 계정 및 로그인](/ko/settings/account)에서 안내에 따라 Google을 연결할 수 있어요.

## 화면 언어 바꾸기

TranslaCat에서는 **한국어·일본어·영어 화면과 학습 모드**를 선택할 수 있어요. 언어 메뉴의 **🇰🇷**는 한국어, **🇯🇵**는 일본어, **EN**은 영어, **🇯🇵🇰🇷**는 학습 모드예요.

이 가이드의 언어는 [한국어](/ko/docs/getting-started), [日本語](/ja/docs/getting-started), [English](/en/docs/getting-started) 링크로 바로 바꿀 수 있어요.

화면 표시 언어와 각 기능에서 사용하는 학습·번역 언어는 다를 수 있어요. 학습이나 번역을 시작할 때는 해당 기능 화면의 언어 설정도 확인해 주세요.

영어 화면은 서비스 언어 메뉴의 **EN**, 영어 설명서는 가이드의 **English**에서 선택해요. 영어로 공부하거나 대화를 번역하려면 각 기능의 대상 언어도 별도로 영어로 설정해 주세요. 영어 학습은 [영어로 학습 시작하기](/ko/docs/language-learning/english)를 참고해 주세요.

## 문제가 생겼을 때

| 상황 | 먼저 확인해 주세요 |
| --- | --- |
| 인증 메일이 오지 않아요 | 이메일 주소와 스팸함을 확인하고, 화면의 재전송 안내를 따라 주세요. |
| 인증 코드가 만료됐어요 | 코드를 다시 보낸 뒤 가장 최근에 받은 코드로 인증해 주세요. |
| 로그인이 되지 않아요 | 가입한 이메일과 비밀번호를 확인해 주세요. Google을 사용했다면 Google 버튼으로 다시 시도해 주세요. |
| 이미 가입된 이메일이라는 안내가 나와요 | 기존 방법으로 로그인해 주세요. 로그인 방법 추가는 설정의 **계정 및 로그인**에서 진행해 주세요. |
| 요청을 처리할 수 없다는 안내가 나와요 | 화면의 안내를 확인하고 잠시 후 다시 시도해 주세요. |

로그인 후에도 도움이 필요하면 [고객센터](/ko/support)의 **1:1 문의 → 문의하기**에서 상황을 알려 주세요. 어떤 화면에서 무엇을 하다가 문제가 생겼는지와 표시된 안내 문구를 적으면 확인에 도움이 돼요.

다른 내용을 살펴보려면 [가이드 홈](/ko/docs)으로 돌아가세요.
