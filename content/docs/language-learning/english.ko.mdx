영어는 **학습·번역 대상 언어**로 사용할 수 있어요. 서비스 언어 버튼의 **EN**으로 영어 화면을 선택하는 것, 가이드의 언어를 바꾸는 것과는 별개예요. 영어 메뉴를 사용해도 학습 언어는 아래에서 따로 설정해 주세요. 영어 설명서는 [English guide](/en/docs/language-learning/english)를 열면 돼요.

## 영어 학습 설정하기

1. **언어 학습 → 설정**에서 [학습 설정](/ko/language-learning/settings)을 열어요. 모바일에서도 학습 화면 위쪽의 **설정**을 눌러요.
2. **원문 언어**에는 한국어 또는 일본어를, **학습 언어**에는 **영어**를 골라요. 원문 언어와 학습 언어는 서로 달라야 해요.
3. **설명·피드백 언어**를 골라요. 영어로 공부하면서 설명은 한국어로 받을 수도 있어요.
4. 하루 목표, 시간대와 음성 기본값을 확인하고 **설정 저장**을 눌러요.

최초 설정은 바로 적용돼요. 기존 설정의 **언어·시간대·하루 목표**를 바꾸면 현재 적용 중인 학습 시간대 기준 다음 학습일부터 반영되므로, **적용 예정 설정**의 날짜를 확인해 주세요. 이미 만들어진 오늘의 문제는 생성 당시 설정을 유지해요. **기본 음성·재생 속도·Listening 방식**은 다음 사용의 기본값으로 즉시 저장돼요.

## 영어 수준 확인하기

1. 변경한 언어가 실제로 적용됐는지 확인한 뒤 [레벨 테스트](/ko/language-learning/level-test)를 열어요.
2. 처음 쓰는 언어쌍에 레벨 테스트가 필요하다는 안내가 나오면 화면 안내에 따라 완료해요. 한 번의 검사는 어휘·문법·읽기·듣기·작문·말하기를 포함한 20문항이에요.
3. **기준 레벨(Base Level)**과 측정된 활동을 확인해요. 일본어로 받은 결과를 영어 수준으로 사용하지 않아요.

<GuideScreenshot src="/images/guides/ko/english-learning-level.jpg" alt="영어 학습 설정에서 내부 기준 레벨을 확인하는 한국어 레벨 테스트 화면" title="현재 영어 학습의 기준 레벨 확인" caption="가이드용 예시 결과를 넣은 실제 화면이에요. 표시된 점수는 설명용이며 사용자의 실제 진단 결과가 아니에요." width={1280} height={900} step={2} locale="ko" />

<Callout title="앱 내부 학습 기준이에요">
  수준은 FOUNDATION / BASIC / INTERMEDIATE / UPPER_INTERMEDIATE / ADVANCED의 내부 Band와 기준 점수로 안내돼요. CEFR 등급이나 공인 시험 성적이 아니에요. 공식 레벨 테스트의 하루 완료 한도는 언어 전체에 공통이므로, 언어를 바꿔도 같은 날의 한도가 초기화되지 않아요.
</Callout>

## 영어로 연습하고 기록 확인하기

- [쓰기](/ko/docs/language-learning/writing)에서는 현재 영어 언어쌍에 맞는 일반 작문을 이용해요. 한국어→일본어 전용 QA 연습이 영어에도 제공되는 것으로 해석하지 않아요.
- [말하기](/ko/docs/language-learning/speaking), [듣기](/ko/docs/language-learning/listening), [읽기](/ko/docs/language-learning/reading)에서는 현재 적용된 학습 언어를 확인한 뒤 시작해요. 평가·코칭과 음성 재생의 사용법은 각 가이드를 따라 주세요.
- 대시보드·현재 프로필·최근 레벨 테스트·일일 작문은 현재 원문/학습 언어쌍을 기준으로 확인해요. 일본어로 공부한 기록은 삭제되지 않으며 [학습 이력](/ko/docs/language-learning/history)에서 해당 활동과 상세 정보를 확인할 수 있어요.
  전체 학습 이력과 연속 학습일은 여러 언어의 활동을 보존하므로, 모든 통계가 언어별로 완전히 나뉘는 것은 아니에요.
- [웹 AI 계획](/ko/docs/language-learning/web-ai)을 쓰면 계획 자체의 원문·학습·피드백 언어도 영어 학습에 맞게 확인해요.

## 완료 확인

현재 적용 설정의 학습 언어가 **영어**이고, 새로 시작하는 활동도 영어인지 확인해요. 아직 일본어로 표시되면 적용 예정 날짜와 오늘 생성된 문제의 언어를 먼저 확인해 주세요.

## 다음에 할 일

영어 대화 번역은 학습 설정과 별개예요. [채팅의 언어 설정](/ko/docs/chat/messages-translation), [채팅 기본값](/ko/docs/settings/chat-defaults), [음성 번역 언어](/ko/docs/voice/languages-storage)에서도 영어를 선택해 주세요.
