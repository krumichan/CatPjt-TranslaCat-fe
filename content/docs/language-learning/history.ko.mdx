제출하거나 저장한 학습 결과를 다시 찾아 복습하는 작업이에요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 기록 찾기

1. [학습 이력](/ko/language-learning/history)을 열어요. PC는 위쪽 **학습 이력**, 모바일은 **이력**을 눌러요.
2. 학습 종류와 조회 기간을 선택해요. 듣기는 학습 방식도 고를 수 있어요.
3. 목록에서 기록을 선택하고 답안·평가·피드백을 읽어요.
4. 복습 버튼이 있는 문제만 안내된 범위에서 다시 풀어요.

## 학습 이력과 누적 근거

**학습 이력**에서는 학습 종류와 기간을 고르고 기록을 선택해요. 쓰기·말하기·듣기·읽기·레벨 테스트·웹 AI와 기존 어휘 기록이 한곳에 모여요. 듣기는 학습 방식으로 추가 필터링할 수 있어요.

PC에서는 목록과 상세가 나란히 표시돼요. 모바일에서는 목록 아래에 상세가 이어지니 기록을 고른 뒤 아래로 스크롤해 주세요. 답안, 평가, 피드백을 확인하고 복습 버튼이 제공되는 경우에만 다시 풀 수 있어요.

**누적 학습 근거**에서는 시작·종료일, 학습 종류, 언어, 결과 종류 등의 조건을 적용해 저장 기록을 조회해요. 최대 조회 범위는 366일이에요. 이 조회가 새 평가를 만들지는 않아요. **원래 학습·피드백 다시 보기**를 누르면 현재 이용 가능한 상세를 확인해요.

코칭과 점수형 평가를 구분해서 읽어 주세요. 원본이 삭제되었거나 음성 보관 기간이 지났다면 일부 내용을 다시 볼 수 없을 수 있어요. 조회 실패는 기록이 없다는 뜻이 아니므로 **다시 시도**나 새로고침을 이용해 주세요.

## 완료 확인

찾은 기록의 날짜와 학습 종류를 확인하고 피드백을 읽어요. 목록이 비어 있으면 조회 조건을 넓혀 보고, 평가 중인 기록은 처리 상태를 확인해 주세요.
