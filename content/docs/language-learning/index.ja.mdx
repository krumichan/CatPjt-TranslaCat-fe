## 学習画面を開く

<Tabs items={["PC", "モバイル"]} groupId="learning-device-ja">
  <Tab value="PC">

    2. 上の **今日の学習** を開き、**Writing / Speaking / Listening / Reading** を選びます。
    3. 記録は **学習履歴**、言語や目標は **設定** で確認します。

PCでもウィンドウ幅が狭い場合はモバイルと同じメニューになります。学習内容と回答方法は共通です。モバイルでは問題と入力欄を上下にスクロールして利用してください。

## ダッシュボードの見方

**統合言語能力** では測定済みの能力や評価範囲、**学習別の成果** では活動別の最近のスコアと今日の進捗を確認できます。推移は期間や学習の種類を切り替えられます。記録が少ない場合は **データ収集中** と表示されます。

**学習プロフィール** には基準レベル、強み・弱み、推奨する学習の方向が表示されます。折りたたまれた内容は開閉ボタンや一括展開で確認してください。初期は実際の学習結果に応じてプロフィールが補正されます。

## 完了の確認と次の学習

回答後は評価状態を確認します。記録は[過去の学習とフィードバックを見る](/ja/docs/language-learning/history)から開けます。準備・評価の失敗や利用上限は、各操作の再試行の案内を参照してください。

学習設定やレベルテストが必要な場合は、案内のボタンから先に完了します。準備済みの問題から回答できる場合は先に進み、残りの準備が中断した場合は再試行ボタンを使ってください。機能が停止中、または本日の上限に達した場合は、表示された案内に従って別の活動を利用するか、後でもう一度試してください。
