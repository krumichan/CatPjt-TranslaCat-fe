## 학습 화면 열기

<Tabs items={["PC", "모바일"]} groupId="learning-device-ko">
  <Tab value="PC">
    1. 왼쪽 메뉴의 **언어 학습** 또는 전체 서비스의 언어 학습 카드를 클릭해요.
    2. 위쪽의 **오늘의 학습**을 열고 **Writing / Speaking / Listening / Reading** 중 하나를 선택해요.
    3. 기록은 **학습 이력**, 학습 언어와 목표는 **설정**에서 확인해요.

    <GuideScreenshot src="/images/guides/ko/language-learning-pc.jpg" alt="PC 언어 학습 대시보드와 오늘의 학습 메뉴" title="PC: 위쪽 메뉴에서 학습 고르기" caption="예시 데이터를 넣은 실제 화면이에요. 대시보드에서 학습 현황을 확인하고 위쪽 메뉴로 원하는 활동에 이동해요." width={1280} height={900} step={1} locale="ko" />
  </Tab>
  <Tab value="모바일">
    1. 왼쪽 위 **☰ 메뉴**를 열고 **언어 학습**을 눌러요.
    2. 학습 화면 위쪽의 **학습**을 누르고 **Writing / Speaking / Listening / Reading**을 선택해요.
    3. **홈 / 이력 / 설정**으로 대시보드, 기록, 학습 설정에 이동해요.

    <GuideScreenshot src="/images/guides/ko/language-learning-mobile.jpg" alt="홈 학습 이력 설정 메뉴가 있는 모바일 언어 학습 화면" title="모바일: 학습 메뉴를 펼쳐 선택" caption="예시 데이터를 넣은 실제 화면이에요. 좁은 화면에서는 메뉴 이름이 짧게 표시되고, 일부 대시보드 영역은 접혀 있어요. ‘펼치기’를 눌러 확인해 주세요." width={390} height={844} step={1} locale="ko" />

PC 창이 좁으면 모바일과 같은 메뉴가 표시될 수 있어요. 학습 내용과 제출 방법은 같으며, 모바일에서는 문제와 입력란을 위아래로 스크롤하며 사용해요.

## 대시보드 읽기

**통합 언어 능력**에서는 측정된 능력과 평가 범위를, **학습별 성과**에서는 활동별 최근 점수와 오늘의 진행도를 확인해요. 추이에서는 조회 기간과 학습 종류를 선택할 수 있어요. 기록이 적을 때는 **데이터 수집 중**으로 표시돼요.

**학습 프로필**에는 기준 레벨, 강점·약점, 추천 학습 방향이 있어요. 접힌 영역의 **펼치기**나 **모두 펼치기**로 내용을 확인해 주세요. 처음에는 실제 학습 결과가 쌓이는 동안 프로필이 보정될 수 있어요.

## 완료 확인과 다음 학습

답안을 제출한 뒤 평가 상태를 확인해요. 기록은 [지난 학습과 피드백 다시 보기](/ko/docs/language-learning/history)에서 다시 열 수 있어요. 준비·평가가 실패하거나 기능 한도 안내가 나오면 각 작업의 재시도 안내를 따라 주세요.

학습 설정이나 레벨 테스트가 필요하다는 안내가 나오면 화면의 버튼으로 먼저 완료해요. 문제 준비 중에는 준비된 문제부터 시작할 수 있고, 나머지 준비가 중단되면 해당 재시도 버튼을 사용해요. 기능이 중지됐거나 오늘 한도에 도달했다면 화면 안내에 따라 다른 활동을 이용하거나 이후에 다시 시도해 주세요.
