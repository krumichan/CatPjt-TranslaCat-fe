Use topics you care about and expressions you want to practice when learning questions are generated.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to use the feature with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Select keywords

1. Open [learning settings](/en/language-learning/settings), scroll down, and find **Learning Keyword (학습 Keyword)**.
2. Select system topics you want. Use the expand button to see their vocabulary.
3. To add your own, enter a type and text under **Add Custom Keyword**, then click **Add (추가)**.
4. Check the selected state and effective date.

## Topics and expressions

Under **Learning Keyword**, select system keywords or ones you added. Selecting a parent **topic** and expanding its child **vocabulary** are separate actions. You can select a broad topic alone or include specific expressions.

To add a custom keyword, enter its type and text and click **Add**. You can edit or deactivate your own keywords. Standard learning can run without selected keywords, but a web AI plan needs keywords available for today.

Before the first Writing question or Speaking session is generated, keyword changes take effect immediately. After generation, changes apply from the next learning day. Check the **Pending application** date.

## Check that you are done

Check that the chosen topics and custom keywords appear in the list. If today's questions already exist, read the notice about application from the next learning day.
