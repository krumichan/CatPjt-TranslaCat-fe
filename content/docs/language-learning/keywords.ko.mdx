관심 있는 주제나 자주 쓰고 싶은 표현을 문제 생성에 활용할 수 있어요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 키워드 선택하기

1. [학습 설정](/ko/language-learning/settings)에서 아래로 스크롤해 **학습 Keyword**를 찾아요.
2. 원하는 시스템 주제를 선택해요. 세부 어휘를 보려면 펼침 버튼을 사용해요.
3. 내 주제를 추가하려면 **Custom Keyword 추가**에서 유형과 내용을 적고 **추가**를 눌러요.
4. 선택 상태와 적용 예정일을 확인해요.

## 관심 주제와 키워드

**학습 Keyword**에서 시스템 키워드 또는 내가 추가한 키워드를 선택해요. 상위 **주제**를 고르는 것과 하위 **어휘** 목록을 펼치는 것은 별개예요. 넓은 주제만 선택하거나 구체적인 표현을 함께 선택할 수 있어요.

직접 추가하려면 **Custom Keyword 추가**에 유형과 내용을 입력하고 **추가**를 눌러요. 내 키워드는 수정하거나 비활성화할 수 있어요. 일반 학습은 키워드를 선택하지 않아도 가능하지만, 웹 AI 계획은 오늘 사용할 수 있는 키워드가 필요해요.

첫 Writing 문제나 Speaking 세션을 생성하기 전에는 키워드 변경이 즉시 적용돼요. 생성한 뒤 바꾸면 다음 학습일부터 적용되므로 **적용 예정** 날짜를 확인해 주세요.

## 완료 확인

선택한 주제와 추가한 키워드가 목록에 보이는지 확인해요. 이미 오늘의 문제를 만들었다면 다음 학습일 적용 안내를 읽어 주세요.
