The level test assesses **six areas in 20 questions**: vocabulary, grammar, reading, listening, writing, and speaking. Allow about 20–25 minutes; three questions involve speaking.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to use the feature with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Start the test

1. Save your [learning settings](/en/language-learning/settings) first. For English practice, check that the effective study language is English.
2. Open the [level test](/en/language-learning/level-test) and click **Start test (테스트 시작)**. The first-visit **Start level test** button also opens it.
3. Check each question's **answer format** and **answer language** before answering. The next question's difficulty adapts to your answers.

PC and mobile use the same questions. On mobile, scroll to check the audio controls, question, and answer field before submitting.

## Answer each question type

| Answer format | What to do |
| --- | --- |
| Multiple choice | Select an answer and click **Submit answer (답변 제출)**. |
| Sentence ordering | Select pieces to build a sentence. Move pieces forward or back, or remove them, when those controls are available. |
| Writing | Write **My answer (내 답변)** in the specified language. Check the given facts, required content, and answer conditions. |
| Listening | Click **Play (재생)**. The level test offers normal speed only; the remaining replay allowance is shown on screen. |
| Speaking | **Allow microphone → Start recording → Stop recording → Preview recording → Submit answer**. For a read-aloud question, check the original audio or text first. |

Allow the microphone in your browser's permission prompt. If it was blocked, change this site's microphone permission from the address bar and retry. Recording is unavailable if another app is using the microphone or your browser does not support it.

## Resume or retry an evaluation

Submitted answers are saved question by question. Return later with **Resume ongoing test (진행 중 테스트 이어하기)** on the landing page. **An unsubmitted recording may be lost after a refresh**, so preview and submit it before leaving.

You cannot edit an answer while it is being evaluated. If an evaluation failure says **Your answer has been saved**, use **Retry evaluation**. If the speech could not be recognized sufficiently, choose **Record again** and submit a new recording. If the answer and evaluation are already saved but the next question fails to load, retry loading rather than restarting the entire test.

## Results and reassessment

After the test, review the overall level, area scores, and suggested difficulty. **Base Level and Band are TranslaCat's internal learning scales**. The five bands are **Foundation, Basic, Intermediate, Upper intermediate, and Advanced**. For English too, these are internal study references; they are not CEFR or JLPT grades and do not award an official language certificate.

Use **Start learning** for an activity or **View learning profile** for strengths and weaknesses. The profile is also below the dashboard; tap **Expand** if it is collapsed on a narrow screen.

Later, use **Recheck level** in learning settings or **Measure again** in your profile to reassess. Previous results remain available. If you have already completed today's official test, follow the displayed restriction and return when allowed. Reopen past results through **Previous results** or [learning history](/en/language-learning/history).

## Check that you are done

Check your answer and its processing status on the result screen. If evaluation is still running, read the feedback when it finishes. You can reopen saved results in learning history.
