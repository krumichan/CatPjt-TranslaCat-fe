レベルテストは語彙・文法・読む・聞く・書く・話すの **6領域、全20問** で現在のレベルを確認します。目安は20～25分です。Speakingが3問あるため、マイクを用意してください。

<Callout title="操作を始める前に">ガイドはログインなしで読めます。実際の操作は自分のアカウントでログインして進めてください。画像は説明用のサンプルデータを使用した実際の画面です。</Callout>

## 開始する

1. 先に[学習設定](/ja/language-learning/settings)を保存します。
2. [レベルテスト](/ja/language-learning/level-test)で **テスト開始** を押します。初回案内の **レベルテスト開始** からも移動できます。
3. 各問題の **回答方式** と **回答言語** を確認します。回答に応じて次の問題の難易度が調整されます。

PCとモバイルで問題は共通です。モバイルでは再生ボタン、問題、入力欄が縦に並ぶ場合があるため、送信する前に必要な内容をスクロールして確認してください。

## 回答方式ごとの操作

| 方式 | 操作 |
| --- | --- |
| 選択式 | 答えを選び、回答の送信ボタンを押します。 |
| 並べ替え | パーツを選び文章を作ります。前後への移動や削除で順序を調整できます。 |
| 記述式 | 指定された言語で回答します。与えられた事実、必須内容、回答条件も確認します。 |
| Listening | **再生** で聞きます。レベルテストは通常速度のみです。残りの再生回数は画面に表示されます。 |
| Speaking | マイクを許可し、録音開始 → 停止 → 録音の確認 → 回答送信の順に進めます。リピート問題は先に原音声やテキストを確認します。 |

ブラウザーからマイクの許可を求められたら許可してください。すでに拒否した場合はアドレスバーのサイト権限から変更します。他のアプリがマイクを使用している場合や、録音に対応していないブラウザーでは利用できません。

## 中断・評価失敗時の対応

送信済みの回答は問題ごとに保存されます。後から開始画面の **進行中のテストを再開** で続けられます。**送信前の録音は再読み込みで失われる場合があります。** 確認後は送信まで済ませてください。

評価中の回答は編集できません。回答保存済みの案内がある場合は評価の再試行を利用します。音声を十分に認識できない場合は再録音してください。回答保存と評価は完了し、次の問題だけ読み込めない場合は、テスト全体をやり直さず読み込みを再試行します。

## 結果と再測定

終了後は総合レベル、領域別スコア、推奨難易度を確認できます。**BandはTranslaCat内部の学習基準** であり、公的な語学資格の等級と同じではありません。

**学習開始** で練習に進むか、**学習プロフィール** から強みと弱みを確認します。プロフィールはダッシュボードの下にもあります。狭い画面で折りたたまれている場合は開いてください。

後から学習設定やプロフィールの再測定ボタンで、現在の実力を再確認できます。過去の結果は保持されます。本日の公式テストを完了済みという案内が出た場合は、画面の制限に従って後で利用してください。過去の結果は **過去の結果** や[学習履歴](/ja/language-learning/history)から確認できます。

## 完了を確認する

結果画面で自分の回答と処理状況を確認してください。評価中の場合は完了後にフィードバックを読み、保存された結果は学習履歴で開けます。
