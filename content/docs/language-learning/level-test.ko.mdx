레벨 테스트는 어휘·문법·읽기·듣기·쓰기·말하기 **6개 영역, 총 20문항**으로 현재 수준을 확인해요. 예상 시간은 약 20~25분이며 말하기 3문항이 포함돼요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 시작하기

1. 먼저 [학습 설정](/ko/language-learning/settings)을 저장해요.
2. [레벨 테스트](/ko/language-learning/level-test)에서 **테스트 시작**을 눌러요. 첫 진입 안내의 **레벨 테스트 시작**으로도 이동할 수 있어요.
3. 문제에 표시된 **답변 방식**과 **답변 언어**를 확인한 뒤 답해 주세요. 답변에 따라 다음 문제의 난이도가 조정돼요.

PC와 모바일 모두 같은 문제를 풀어요. 모바일에서는 음성 재생 버튼, 문제, 답변 입력란이 화면 아래에 이어질 수 있으니 제출 전에 필요한 내용을 스크롤해 확인해 주세요.

## 문제 유형에 맞춰 답하기

| 답변 방식 | 조작 방법 |
| --- | --- |
| 선택형 | 알맞은 답을 고른 뒤 **답변 제출**을 눌러요. |
| 문장 순서 | 조각을 선택해 문장을 만들어요. 필요한 경우 앞으로·뒤로 이동하거나 제거해 순서를 조정해요. |
| 글쓰기 | 지정된 언어로 **내 답변**을 작성해요. 주어진 사실, 반드시 표현할 내용, 답변 조건이 있으면 함께 확인해요. |
| 듣기 | **재생**으로 음성을 들어요. 레벨 테스트는 정상속도만 제공하며, 추가 재생 가능 횟수는 화면에 표시돼요. |
| 말하기 | **마이크 허용 → 녹음 시작 → 녹음 정지 → 녹음 미리듣기 → 답변 제출** 순서로 진행해요. 따라 말하기라면 원본 음성이나 텍스트를 먼저 확인해요. |

브라우저의 마이크 권한 창이 뜨면 사용할 마이크를 허용해 주세요. 이미 차단했다면 주소창의 사이트 권한에서 변경한 뒤 다시 시도해요. 다른 앱이 마이크를 점유하거나 녹음을 지원하지 않는 브라우저에서는 사용할 수 없어요.

## 중단하거나 평가가 실패했을 때

제출한 답변은 문제별로 저장돼요. 나중에 테스트 첫 화면의 **진행 중 테스트 이어하기**로 돌아올 수 있어요. **제출 전 녹음은 새로고침하면 사라질 수 있으니**, 미리듣기 후 제출까지 마쳐 주세요.

평가 중에는 답변을 수정할 수 없어요. 평가 실패 안내에 **답변은 저장되어 있습니다**가 보이면 **평가 다시 시도**를 사용해요. 음성을 충분히 인식하지 못했다는 안내라면 **다시 녹음하기**로 새 음성을 제출해 주세요. 답변 저장과 평가가 끝났는데 다음 문제만 불러오지 못했다면 전체 테스트를 다시 시작하지 말고 불러오기를 다시 시도해요.

## 결과와 재측정

테스트를 마치면 종합 레벨, 영역별 점수, 추천 학습 난이도를 확인해요. 표시되는 **Band는 TranslaCat 내부 학습 기준**이며 공인 어학 등급과 같지 않아요.

**학습 시작**으로 활동을 시작하거나 **학습 프로필 보기**로 강점·약점을 확인해요. 프로필은 대시보드 아래에도 있어요. 좁은 화면에서 접혀 있으면 **펼치기**를 눌러 주세요.

나중에는 학습 설정의 **레벨 재확인**이나 프로필의 **다시 측정하기**로 현재 실력을 다시 확인할 수 있어요. 과거 결과는 보존돼요. 당일 공식 테스트를 이미 완료했다는 안내가 나오면 화면의 제한에 따라 이후 다시 이용해 주세요. 지난 결과는 **이전 결과** 또는 [학습 이력](/ko/language-learning/history)에서 확인해요.

## 완료 확인

결과 화면에서 내 답변과 처리 상태를 확인해 주세요. 평가 중이라면 완료 후 피드백을 읽고, 저장된 결과는 학습 이력에서 다시 열 수 있어요.
