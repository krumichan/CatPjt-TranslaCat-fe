[Listening](/en/language-learning/listening) asks you to listen to AI audio and answer questions about it. Open **Today's practice → Listening** on PC or **Practice → Listening** on mobile.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to use the feature with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Choose today's format

| Format | What to do |
| --- | --- |
| Dictation and meaning | Write what you hear in the study language and its meaning in the source language. |
| Listening comprehension | Listen for meaning, intention, and details, then select an answer. |
| Key-point summary | Summarize the main points and important information in the study language. |

Click **Start this type** on the card you want. Selecting a type prepares five questions and their audio. You can complete one type or add another. Use **Continue / Resume learning** for an ongoing activity or **View results** after completion.

## Listen and submit

1. Click **Play / Listen again**. Use **0.75x slow playback** if needed.
2. Answer in the language shown. If both dictation and meaning are required, complete both fields.
3. Select an answer for multiple choice, or type the main points for a summary.
4. Click **Submit selected answers**. Once answers are saved, AI evaluation runs in the background and you can continue to the next question.

Submission is the same on PC and mobile. On mobile, audio controls and answer fields stack vertically; scroll to the submit button below them.

If the session includes a **read-aloud** field, follow **request microphone permission → start recording → stop recording → preview → Confirm this audio**, then submit the answer. Check the screen for recording limits and the available rerecording allowance.

Unsubmitted text and recordings are not automatically available on every device. Submit required answers before leaving the screen.

## When you need help

You can use **Topic hint / Keyword hint**, replay, and slow playback. Review the result's assistance-use and independent-listening information alongside the answer evaluation.

Choosing **Show answer** first opens a confirmation. Continuing excludes **all selected tasks for that question** from official evaluation, today's completion count, and the learning profile. You can read the answer and move to **Next question**. **Skip** also does not count toward today's completed total.

## Results and retries

After the last submission, the result screen opens. If AI evaluation is still running, it shows progress even though you finished answering. Accepted evaluations continue if you leave or refresh the page.

When evaluation finishes, review your answer, the correct answer or reference meaning, feedback, and question scores. If only some questions were evaluated, read **Evaluations included ○/○**. Failed or excluded questions are left out of the final average rather than treated as zero.

Use **Retry evaluation** on one failure or **Retry all failed evaluations**. If **Try again as practice** is offered, review within the displayed retry allowance.

If recognition or pronunciation evaluation differs from your recording, use **Report speech recognition/evaluation error** and provide its type and details. Check the audio-retention consent. Once audio retention has expired, the original audio may no longer play; the report screen explains what can be reported with the information remaining.

If question preparation stops, use its retry button. If the session has expired, choose **Start new Session**. Reopen saved results under **Listening** in [learning history](/en/language-learning/history).

## Check that you are done

Check your answer and its processing status on the result screen. If evaluation is still running, read the feedback when it finishes. You can reopen saved results in learning history.
