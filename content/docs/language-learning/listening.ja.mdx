[Listening](/ja/language-learning/listening)はAI音声を聞いて理解した内容に答える活動です。PCは **今日の学習 → Listening**、モバイルは **学習 → Listening** を開きます。

<Callout title="操作を始める前に">ガイドはログインなしで読めます。実際の操作は自分のアカウントでログインして進めてください。画像は説明用のサンプルデータを使用した実際の画面です。</Callout>

## 今日の形式を選ぶ

| 形式 | 内容 |
| --- | --- |
| ディクテーション + 意味 | 学習言語で書き取り、原文言語で意味を書きます。 |
| 聞いて答えを選ぶ | 内容・意図・詳細を聞き、適切な選択肢を選びます。 |
| 要点をまとめる | 要点と重要情報を学習言語でまとめます。 |

カードの開始ボタンを押すと、選んだ形式の5問と音声を準備します。1種類だけでも、別の形式を追加しても構いません。開始済みの場合は続きからの学習、完了後は結果を見るボタンを利用します。

## 聞いて回答する

1. 再生ボタンで音声を聞きます。必要なら **0.75x** のゆっくり再生を使います。
2. 表示された言語で回答します。書き取りと意味の両方を求める問題は、両方の欄に入力してください。
3. 選択式は答えを選び、要点整理は自分の文章で入力します。
4. 回答を送信します。保存後はAI評価がバックグラウンドで進むため、次の問題に続けられます。

PCとモバイルの送信方法は共通です。モバイルでは再生ボタンや入力欄が縦に並ぶため、下の送信ボタンまでスクロールしてください。

リピート発話の入力欄が提供されるセッションは、マイクの許可 → 録音開始 → 停止 → 確認 → 音声の確定でアップロードしてから回答します。再録音回数と録音時間の上限は画面で確認してください。

送信前の入力や録音が、すべての端末に自動保存されるわけではありません。画面を離れる前に必要な回答を送信してください。

## 学習補助を使う

**Topicヒント / Keywordヒント**、再生、ゆっくり再生を利用できます。結果では回答の評価とともに、補助の使用や独立した聞き取りの情報も確認してください。

**正解を見る** を先に押すと確認画面が表示されます。続行すると、その問題の選択Task全体が正式評価、今日の完了数、学習プロフィールから除外されます。正解を確認後は次へ進めます。スキップした問題も今日の完了数には含まれません。

## 結果と再試行

最後の回答後は結果画面に移動します。回答を終えてもAI評価が残っている場合は進捗が表示されます。画面を離れたり再読み込みしたりしても、受け付け済みの評価は継続します。

完了後は回答、正解や参考の意味、フィードバック、問題別スコアを確認します。一部のみ評価された場合は反映された問題数も確認してください。エラーや評価対象外の問題は0点として扱わず、最終平均から除外されます。

評価に失敗した場合は、問題別または失敗分すべての再試行を利用できます。練習の再挑戦ボタンがある問題は、表示された回数制限内で復習できます。

音声認識や発音評価が実際と違う場合は、**音声認識・評価エラーを報告** から種類と説明を送ります。音声保管の同意内容を確認してください。保管期限後は原音声を再生できない場合があり、報告画面では残っている情報に応じた案内が表示されます。

問題の準備が中断した場合は準備の再試行を利用してください。セッション期限切れの案内が出た場合は新しいSessionを開始します。保存した結果は[学習履歴](/ja/language-learning/history)から確認できます。

## 完了を確認する

結果画面で自分の回答と処理状況を確認してください。評価中の場合は完了後にフィードバックを読み、保存された結果は学習履歴で開けます。
