[Listening](/ko/language-learning/listening)은 AI 음성을 듣고 이해한 내용을 답하는 활동이에요. PC는 **오늘의 학습 → Listening**, 모바일은 **학습 → Listening**에서 열어요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 오늘의 유형 선택하기

| 유형 | 하는 일 |
| --- | --- |
| 받아쓰기 + 해석 | 들은 문장을 학습 언어로 받아쓰고, 뜻을 원문 언어로 적어요. |
| 듣고 답 고르기 | 음성의 내용과 의도, 세부 정보를 듣고 알맞은 답을 골라요. |
| 핵심 정리 | 들은 내용의 요점과 중요한 정보를 학습 언어로 정리해요. |

원하는 카드에서 **이 유형 시작하기**를 눌러요. 유형을 선택하면 해당 5문제와 음성을 준비해요. 한 유형만 풀어도 되고 다른 유형을 추가로 학습해도 돼요. 이미 진행 중이라면 **계속하기 / 이어서 학습하기**, 완료했다면 **결과 보기**를 사용해요.

## 듣고 제출하기

1. **재생 / 다시 듣기**를 눌러 음성을 들어요. 필요하면 **0.75x 천천히**를 이용해요.
2. 화면에 표시된 언어에 맞춰 답해요. 받아쓰기와 의미 쓰기를 모두 요구하는 문제는 두 칸을 작성해 주세요.
3. 선택형은 답을 고르고, 핵심 정리는 요점을 직접 입력해요.
4. **선택 답안 제출**을 눌러요. 답안 저장 후 AI 평가는 백그라운드에서 진행되어 다음 문제를 계속 풀 수 있어요.

PC와 모바일의 제출 방식은 같아요. 모바일에서는 음성 버튼과 입력란이 세로로 이어지므로 아래쪽 제출 버튼까지 스크롤해 주세요.

**따라 말하기** 입력란이 제공되는 세션에서는 마이크 권한 요청 → 녹음 시작 → 녹음 정지 → 녹음 미리 듣기 → **이 Audio 확정** 순서로 음성을 올린 뒤 답안을 제출해요. 다시 녹음 가능한 횟수와 녹음 제한 시간은 해당 화면에서 확인해 주세요.

제출 전 입력과 녹음이 모든 기기에 자동으로 저장되는 것은 아니에요. 화면을 떠나기 전에 필요한 답안을 제출해 주세요.

## 도움이 필요할 때

**Topic 힌트 / Keyword 힌트**, 다시 듣기와 느리게 듣기를 사용할 수 있어요. 결과에서는 답안 평가와 보조 사용·독립 청취 정보를 함께 확인해 주세요.

**정답 보기**를 먼저 누르면 확인창이 떠요. 계속하면 해당 문제의 선택 과제 전체가 공식 평가, 오늘 완료 수, 학습 프로필에서 제외돼요. 정답을 읽고 **다음 문제**로 진행할 수 있어요. **건너뛰기**도 오늘 완료 수에 포함되지 않아요.

## 결과와 재시도

마지막 답안을 제출하면 결과 화면으로 이동해요. 문제 풀이를 마쳤어도 AI 평가가 남아 있으면 처리 진행도가 표시돼요. 화면을 벗어나거나 새로고침해도 접수된 평가는 계속 진행돼요.

평가 완료 후 내 답안, 정답·참고 의미, 피드백과 문제별 점수를 확인해요. 전체 중 일부만 평가됐다면 **평가 반영 ○/○**를 함께 읽어 주세요. 오류나 평가 제외 문제는 0점 처리하지 않고 최종 평균에서 제외돼요.

실패한 평가는 개별 **평가 다시 시도** 또는 **실패한 평가 모두 다시 시도**로 재요청할 수 있어요. **연습으로 다시 해보기**가 제공되는 문제는 화면의 재도전 한도 안에서 복습해요.

음성 인식·발음 평가가 실제와 다르면 **음성 인식·평가 오류 신고**에서 유형과 설명을 보내요. 음성 보관 동의를 확인해 주세요. 음성 보관 기간이 끝났다면 원음 재생은 불가능할 수 있으며, 신고 화면은 남아 있는 정보로 안내해요.

문제 준비가 중단되면 준비 재시도 버튼을 이용해요. 세션이 만료됐다는 안내가 나오면 **새 Session 시작**으로 이동해요. 저장된 결과는 [학습 이력](/ko/language-learning/history)의 **듣기**에서 다시 확인할 수 있어요.

## 완료 확인

결과 화면에서 내 답변과 처리 상태를 확인해 주세요. 평가 중이라면 완료 후 피드백을 읽고, 저장된 결과는 학습 이력에서 다시 열 수 있어요.
