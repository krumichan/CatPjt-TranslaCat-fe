[Reading](/en/language-learning/reading) asks you to read passages and answer questions about them. On PC, choose **Today's practice → Reading**; on mobile, choose **Practice → Reading**.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to use the feature with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Choose a reading format

| Format | What you practice |
| --- | --- |
| Reading comprehension | Main content, details, causes and effects, intention, and inference. |
| Main ideas and structure | Key points, titles, paragraph roles, and the flow of the text. |
| Context inference | Referents, omitted meaning, sentence intention, and what comes next. |

Click **Start this format**. You can choose just the formats you need. Questions generated today remain when you return. The screen shows **Continue** for an ongoing activity and **View results** after completion.

If advanced structural analysis is unavailable, choose another format. Check availability on screen before starting.

## Read and answer

1. Read the **passage** and question.
2. Select an option, or click sentence pieces in order to form the sequence. Use **Reset order** to begin an ordering answer again.
3. Click **Submit answer**.
4. Read whether it was correct and the supporting **evidence**, then choose **Next question**. If **Answer again** is offered on a mistake, you can retry as review.

On mobile, scroll below a long passage to reach the question and submit button. PC layout also changes with window width; choosing and submitting work the same way.

The official score uses your **first submission**. Correct answers during review are shown separately from that first attempt.

## Results and expression review

After learning, check the first-attempt correct count and the detailed abilities. Use **Review incorrect questions** and find the supporting passage text. Revisit **Expressions in the passage** in their original context.

New standalone **Daily Vocabulary** activities have ended. Continue new vocabulary practice through Reading's **context inference** and **passage expression review**. Existing Vocabulary questions and history are preserved. The [Vocabulary screen](/en/language-learning/vocabulary) offers navigation to Reading or existing records.

## If preparation or answer processing fails

You can start with questions already prepared. If preparation of the rest stops, click **Retry preparing remaining questions**. Existing questions and answers remain. If answer processing fails, check the current question state before submitting again.

Find past reading and vocabulary results by activity and period in [learning history](/en/language-learning/history).

## Check that you are done

Check your answer and its processing status on the result screen. If evaluation is still running, read the feedback when it finishes. You can reopen saved results in learning history.
