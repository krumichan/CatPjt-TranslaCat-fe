[Reading](/ko/language-learning/reading)은 지문과 문제를 읽고 이해한 내용을 답하는 활동이에요. PC에서는 **오늘의 학습 → Reading**, 모바일에서는 **학습 → Reading**을 선택해요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 읽기 형식 선택하기

| 형식 | 연습 내용 |
| --- | --- |
| 독해 문제 | 지문의 내용, 세부 정보, 원인과 결과, 의도와 추론을 확인해요. |
| 요점·구조 파악 | 핵심 내용과 제목, 문단의 역할과 글의 흐름을 파악해요. |
| 문맥 추론 | 지시하는 대상, 생략된 의미, 문장 의도와 다음 전개를 추론해요. |

원하는 형식의 **이 형식 시작하기**를 눌러요. 필요한 형식만 골라 학습해도 돼요. 오늘 생성된 문제는 다시 들어와도 유지되고, 진행 중은 **계속하기**, 완료 후에는 **결과 보기**가 표시돼요.

고급 구조 분석을 제공할 수 없다는 안내가 나오면 다른 형식을 선택해 주세요. 화면에서 제공 여부를 확인한 뒤 시작할 수 있어요.

## 지문을 읽고 답하기

1. **지문**과 문제를 읽어요.
2. 알맞은 선택지를 고르거나, 문장 조각을 차례로 눌러 순서를 만들어요. 순서 문제는 **순서 초기화**로 처음부터 고를 수 있어요.
3. **답변 제출**을 눌러요.
4. 정오답과 **근거**를 읽고 **다음 문제**로 이동해요. 틀린 문제에 **다시 답하기**가 있으면 복습으로 재도전할 수 있어요.

모바일은 긴 지문을 읽은 뒤 아래쪽 문제와 제출 버튼까지 스크롤해요. PC도 창 너비에 따라 배치가 달라질 수 있으며, 선택과 제출 방식은 같아요.

공식 점수는 **첫 제출**을 기준으로 해요. 복습에서 맞힌 결과는 첫 답변과 구분해 표시돼요.

## 결과와 표현 복습

학습을 마치면 첫 제출 정답 수와 세부 능력을 확인해요. **틀린 문제 다시 보기**로 오답을 확인하고 지문의 어떤 부분이 근거인지 찾아보세요. **지문 속 표현**에 표시된 단어와 표현은 원문 문맥에서 다시 읽으면 도움이 돼요.

별도의 **Daily Vocabulary 신규 제공은 종료**됐어요. 새 어휘 이해 연습은 Reading의 **문맥 추론**과 **지문 속 표현 복습**에서 이어가세요. 기존 Vocabulary 문제와 학습 이력은 보존되며, [Vocabulary 화면](/ko/language-learning/vocabulary)에서 Reading 또는 기존 이력으로 이동할 수 있어요.

## 준비가 중단되거나 답변이 실패할 때

준비된 문제부터 학습할 수 있어요. 나머지 준비가 중단되면 **나머지 문제 준비 재시도**를 눌러요. 기존 문제와 답변은 유지돼요. 답변 처리 실패 안내가 나오면 현재 문제 상태를 확인하고 다시 제출해 주세요.

지난 읽기·어휘 결과는 [학습 이력](/ko/language-learning/history)에서 종류와 기간을 골라 볼 수 있어요.

## 완료 확인

결과 화면에서 내 답변과 처리 상태를 확인해 주세요. 평가 중이라면 완료 후 피드백을 읽고, 저장된 결과는 학습 이력에서 다시 열 수 있어요.
