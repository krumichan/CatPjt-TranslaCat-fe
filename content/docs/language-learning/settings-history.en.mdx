Set your study language, daily goals, and default audio options here. These settings are separate from account settings in the profile menu.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to use the feature with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Save your learning settings

On PC or mobile, choose **Settings (설정)** at the top of the learning screen to open [learning settings](/en/language-learning/settings).

1. Choose different **source language (원문 언어)** and **Learning language (학습 언어)** values. To study English, choose **English** as the study language and Korean or Japanese as the source language.
2. Choose the **explanation and feedback language (설명·피드백 언어)**. Web AI learning plans use this for question explanations and feedback.
3. Set the **daily sentence count**, **daily Speaking goal**, and **daily Listening goal** within the ranges shown.
4. Check the default Speaking voice and playback speed, default Listening tasks, and **learning timezone**. Enter a timezone such as Asia/Seoul or Asia/Tokyo.
5. Click **Save settings (설정 저장)** and check the completion notice.

Initial settings can be used immediately. Later changes to languages, the learning timezone, and daily goals take effect from the next learning day in the current learning timezone. Check the date under **Scheduled settings changes (적용 예정 설정)**. Questions already created today keep the settings used when they were generated.

Default Speaking voice and playback speed, and the default Listening task selection, are saved immediately. They do not replace an existing session's options. Select at least **dictation** or **read aloud** for Listening; writing the meaning is optional.

## English study and display language

English as a study language controls the language you practice. To change application menus and buttons, use **Language → EN (English)** instead. The service offers Korean, Japanese, English, and Learning mode interfaces. The documentation language selector at /en/docs is independent of both settings.

## Check that you are done

Check the save confirmation and current settings. If pending settings appear, read their date. Continue any questions already generated today with their original settings.
