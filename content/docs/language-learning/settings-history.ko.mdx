학습할 언어, 하루 목표와 음성 기본값을 정하는 작업이에요. 프로필 메뉴의 계정 설정과는 별개예요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 기본 학습 설정

PC와 모바일 모두 학습 화면 위쪽의 **설정**에서 [언어 학습 설정](/ko/language-learning/settings)을 열어요.

1. **원문 언어**와 **학습 언어**를 서로 다르게 선택해요.
   한국어·일본어·영어를 선택할 수 있어요. 영어로 시작하는 전체 절차는 [영어로 학습 시작하기](/ko/docs/language-learning/english)를 참고해 주세요.
2. **설명·피드백 언어**를 선택해요. 웹 AI 학습 계획의 문제 설명과 피드백에 사용해요.
3. **하루 학습 문장 수**, **하루 Speaking 목표**, **하루 Listening 목표**를 화면에 표시된 허용 범위에서 정해요.
4. 기본 Speaking 음성·재생 속도, 기본 Listening 학습 방식, **학습 기준 Timezone**을 확인해요. 시간대는 `Asia/Seoul`, `Asia/Tokyo`처럼 입력해요.
5. **설정 저장**을 눌러 완료 안내를 확인해요.

최초 설정은 바로 사용할 수 있어요. 이후 변경은 **적용 예정 설정**의 날짜를 확인해 주세요. 이미 생성된 오늘의 문제는 생성 당시 설정을 유지해요. 기본 Listening 방식은 화면 안내대로 다음 세션의 기본값에 즉시 저장돼요. 받아쓰기 또는 따라 말하기 중 하나 이상을 선택해야 하며 의미 쓰기는 선택 사항이에요.

## 완료 확인

설정 저장 완료 안내와 현재 설정을 확인해요. 적용 예정 설정이 보이면 날짜를 확인하고, 오늘 이미 만든 문제는 기존 설정으로 이어서 학습해요.
