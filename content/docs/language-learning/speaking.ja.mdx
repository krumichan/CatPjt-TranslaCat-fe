[Speaking](/ja/language-learning/speaking)はマイクで録音した回答を送り、AIと練習する機能です。PCは **今日の学習 → Speaking**、モバイルは **学習 → Speaking** を開きます。

<Callout title="操作を始める前に">ガイドはログインなしで読めます。実際の操作は自分のアカウントでログインして進めてください。画像は説明用のサンプルデータを使用した実際の画面です。</Callout>

## 形式とトピックを選ぶ

1. **聞いてリピート / ガイド付きSpeaking / 自由Speaking** から形式を選びます。
2. 自分のキーワードに基づくトピック、または直接入力する自由トピックを選びます。キーワードがない場合は学習設定で選択するか、自由トピックを利用してください。
3. **Session設定** で訂正方法、目標時間、AI音声、再生速度を確認します。自由Speakingでは会話目標やAIの役割も任意で入力できます。
4. **Speaking開始** を押し、問題や状況の準備を待ちます。

リピートとガイド付きSpeakingはAIが先に文章やガイドを提示します。進行中のセッションがある場合は **続きから学習** で再開してください。進行中セッションの確認に失敗した場合は先に再確認します。

## 録音して回答する

1. マイクの権限をリクエストし、ブラウザーで許可します。
2. 文章、ガイド、AIの質問を確認し、録音を開始します。
3. 話し終えたら録音を停止し、自分の録音を聞いて確認します。必要なら再録音します。
4. 回答を送信します。音声認識とAI応答の準備後、記録とAI音声を確認できます。

通常の会話録音は最低1秒、1回最大60秒です。時間やファイルサイズの制限が表示されたら短く録り直してください。録音中に画面を離れると、現在の録音が失われる場合があります。

## 聞いてリピート

今日の5問を順番に練習します。AI音声とスクリプトを確認し、**同じ文章を最低2回** 話します。必要に応じて3回目も追加できます。

認識がうまくいかなかった発話は、その発話の再録音ボタンで置き換えます。有効な発話がそろったら問題を評価して次へ進み、最後は最終問題の評価を依頼します。問題別の状態で待機・評価中・完了・失敗を確認できます。

## ガイド付き・自由Speakingと補助

ガイド付きSpeakingは与えられた事実と必須内容をもとに自分の言葉で話します。自由Speakingはテーマに沿って会話します。メモ欄にはキーワードや話す順序を残せます。メモは下書き保存されますがAI評価には送信されません。

難しい時は **学習補助** の再生、ゆっくり再生、質問の再表示、ヒント、翻訳、回答例を利用できます。利用履歴は結果からも確認してください。AIの例文と、自分が実際に話した内容を区別して復習しましょう。

## 終了と結果

**終了してコーチングを受ける** が表示される場合は、保存された発話から会話コーチングを準備します。このコーチングは総合スコアや能力プロフィールに反映されません。

スコア評価を行うセッションでは評価の準備状況を確認し、**終了して評価を受ける** を押します。条件不足の場合は会話を続けるか **評価なしで終了** を選べます。評価なしでも履歴と学習時間は保持されますが、スコアと学習プロフィールには反映されません。終了後は新しい回答を追加できないため、確認して終了してください。

評価やコーチングの準備中は状態を確認します。失敗した場合は結果画面の再試行を利用してください。完了した結果と会話は[学習履歴](/ja/language-learning/history)のSpeakingから再確認できます。

## 音声認識が違うとき

先に自分の録音を聞き直してください。認識文は実際の発話と異なる場合があります。必要なら再録音するか、STTエラー報告で種類と実際の発話を入力します。報告時は原音声の保管に関する同意内容を確認してください。さらにサポートが必要な場合は、報告完了画面から問い合わせを依頼できます。

一部の処理だけ失敗した場合は、失敗段階の再試行やTTSのみの再生成など、表示された操作を利用します。評価対象外にすると記録は残ってもスコアに反映されないため、確認メッセージを読んでください。

## 完了を確認する

結果画面で自分の回答と処理状況を確認してください。評価中の場合は完了後にフィードバックを読み、保存された結果は学習履歴で開けます。
