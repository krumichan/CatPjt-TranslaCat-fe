[Speaking](/ko/language-learning/speaking)은 마이크로 녹음한 답변을 보내고 AI와 연습하는 기능이에요. PC에서는 **오늘의 학습 → Speaking**, 모바일에서는 **학습 → Speaking**을 선택해요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 방식과 주제 고르기

1. **듣고 따라 말하기 / 가이드 말하기 / 자유 말하기** 중 원하는 형식을 선택해요.
2. **내 키워드 기반 Topic** 또는 **직접 Topic 입력**을 골라요. 키워드를 사용할 수 없다면 학습 설정에서 선택하거나 직접 주제를 입력해요.
3. **Session 설정**에서 교정 방식, 목표 시간, AI 음성, 재생 속도를 확인해요. 자유 말하기에서는 대화 목표와 AI 역할도 선택적으로 적을 수 있어요.
4. **Speaking 시작**을 눌러 문제나 대화 상황이 준비될 때까지 기다려요.

따라 말하기와 가이드 말하기는 AI가 먼저 문장이나 가이드를 보여줘요. 진행 중인 세션이 있다면 **이어서 학습**으로 돌아가세요. 진행 중 세션을 확인하지 못했다는 안내가 나오면 **다시 확인**을 먼저 눌러 주세요.

## 마이크로 답변 보내기

1. **마이크 권한 요청**을 누르고 브라우저 권한을 허용해요.
2. 제시된 문장·가이드·AI 질문을 확인한 뒤 **녹음 시작**을 눌러요.
3. 말을 마치면 **녹음 종료**, **내 녹음 미리 듣기**로 확인해요. 바꾸려면 **다시 녹음**을 눌러요.
4. **답변 보내기**를 눌러요. 음성 인식과 AI 응답 준비가 끝나면 대화 기록과 AI 음성을 확인해요.

일반 대화 녹음은 최소 1초, 한 번에 최대 60초예요. 시간이나 파일 크기 제한이 표시되면 더 짧게 다시 녹음해 주세요. 녹음 중 화면을 떠나면 현재 녹음을 잃을 수 있어요.

## 듣고 따라 말하기

오늘의 5문제를 순서대로 연습해요. 각 문제의 AI 음성과 스크립트를 확인하고 **같은 문장을 최소 두 번** 말해요. 필요하면 세 번째 발화를 추가할 수 있어요.

인식이 잘못된 발화는 해당 발화의 **다시 녹음**으로 교체해요. 유효한 발화가 준비되면 **이 문제 평가하고 다음으로**를 누르고, 마지막에는 **마지막 문제 평가하기**를 눌러요. 문제별 평가 상태에서 대기·평가 중·완료·실패를 확인할 수 있어요.

## 가이드·자유 말하기와 학습 보조

가이드 말하기는 주어진 사실과 필수 내용을 확인해 내 말로 구성해요. 자유 말하기는 제시된 주제에 맞춰 AI와 대화해요. **내 메모**에 키워드나 말할 순서를 적을 수 있어요. 이 메모는 자동 임시 저장되지만 AI 평가에는 전송되지 않아요.

어려우면 **학습 보조**에서 다시 듣기, 느리게 듣기, 질문 다시 보기, 힌트, 번역, 예시 답안을 이용해요. 사용 내역은 학습 기록에 남으므로 결과에서 함께 확인해 주세요. AI가 만든 예시와 내가 실제로 말한 내용은 구분해서 복습해요.

## 종료와 결과 확인

화면에 **종료하고 코칭 받기**가 보이면 저장된 발화를 바탕으로 대화 코칭을 준비해요. 이 코칭은 종합 점수나 능력 프로필에 반영되지 않아요.

점수형 평가가 제공되는 세션은 **Speaking 평가 준비도**를 확인하고 **종료하고 평가받기**를 눌러요. 조건이 부족하면 더 대화하거나 **평가 없이 종료하기**를 선택할 수 있어요. 평가 없이 종료해도 이력과 학습 시간은 보존되지만 점수와 학습 프로필에는 반영되지 않아요. 종료한 세션에는 새 답변을 추가할 수 없으니 확인 후 종료해 주세요.

평가나 코칭을 준비하는 동안에는 진행 상태를 확인해요. 실패하면 결과 화면의 재시도 버튼을 이용해요. 완료된 결과와 대화는 [학습 이력](/ko/language-learning/history)의 **말하기**에서 다시 확인할 수 있어요.

## 음성 인식이 틀렸을 때

먼저 내 녹음을 다시 들어보세요. 인식 문장은 실제 발화와 다를 수 있어요. 필요하면 다시 녹음하거나 **STT 오류 신고**를 눌러 오류 유형과 실제 발화 내용을 알려 주세요. 신고 화면에서 원본 음성 보관 동의 내용을 확인해 주세요. 추가 지원이 필요하면 신고 완료 화면의 **고객 문의 요청**을 이용할 수 있어요.

일부 처리만 실패했다면 **실패 단계 재시도**나 **TTS만 다시 생성**처럼 화면에 제공되는 버튼을 사용해요. 평가 제외를 선택하면 해당 발화는 기록에 남아도 점수에는 반영되지 않으니 확인 안내를 읽어 주세요.

## 완료 확인

결과 화면에서 내 답변과 처리 상태를 확인해 주세요. 평가 중이라면 완료 후 피드백을 읽고, 저장된 결과는 학습 이력에서 다시 열 수 있어요.
