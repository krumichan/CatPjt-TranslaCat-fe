外部のWeb AIで進める学習を準備し、結果をTranslaCatの学習履歴に取り込む操作です。

<Callout title="操作を始める前に">ガイドはログインなしで読めます。実際の操作は自分のアカウントでログインして進めてください。画像は説明用のサンプルデータを使用した実際の画面です。</Callout>

## Web AI学習プランを作る

Web AIプランは、外部AIで学ぶ条件と結果の送信方法を準備する機能です。**保存するだけでは外部AIに予定は登録されません。** コピーしたプロンプトを利用先のWeb AIに直接登録してください。

1. 学習設定の **Web AI学習プラン → プランを管理** を開き、基本設定と今日有効なキーワードの準備状況を確認します。
2. **新しいプラン** で名前を入力します。言語は現在有効な基本学習設定を使います。
3. 毎日・毎週・毎月から繰り返しを選び、曜日や日付、時刻、タイムゾーンを設定します。その月にない日付は実行せず、毎月末日も選べます。
4. Writing・Reading・Speaking・Listeningの詳細形式と難易度別の問題数を選びます。少なくとも1問以上が必要です。
5. 基本キーワードを使うか、このプラン専用に選ぶかを決めます。場面やテーマは任意で追加できます。
6. **学習プランを保存** を押します。

## プロンプトのコピーと連携

保存後は **プロンプトをコピー** や **連携プロンプトを作成** で実際の文面を準備して確認します。コピーがブロックされた場合は **全選択** して手動でコピーできます。

プロンプトには **プラン専用の接続キー** が含まれます。利用するWeb AIにのみ貼り付け、公開投稿や共有文書には載せないでください。最初の準備や **接続キーを交換** では既存キーが変わります。登録済みの予定にも新しいプロンプトを貼り直してください。同じページでの再コピーではキーを交換しません。**連携を解除** すると以前のプロンプトでは接続できなくなります。

HTTPリクエストに対応したWeb AIは問題取得と結果送信を行えます。サービスURLに外部から接続できる必要があります。非対応のAIは1回分を学習し、結果JSONを手動で取り込んでください。外部AIの予定機能の対応状況や実行状態は、利用先でも確認してください。

## 結果JSONの取り込みと検証

1. プランの結果取り込みから、今回の送信用プロンプトを準備します。
2. Web AIの案内で学習し、結果JSONを受け取ります。
3. **Web AIの結果JSON** にそのまま貼り付け、**結果の保存とAI検証** を押します。1回に10問までに分けて取り込めます。
4. [学習履歴](/ja/language-learning/history)の **Web AI** で検証状況、学習フィードバック、Web AIの原文を確認します。

外部AIの参考スコアとTranslaCatの反映スコアは異なる場合があります。**検証が完了した問題のみ** 反映されます。本文・音声などの根拠不足や難易度・言語の不一致によって、スコア未反映またはコーチングとして記録される場合があります。状態と理由を合わせて確認してください。

検証失敗時は **AI検証を再試行** を利用できます。処理中や再試行上限の場合は表示された案内に従ってください。保存された回答と原文は保持されます。言語設定の変更やプランの一時停止がある場合は、新しいプロンプトやプラン状態の確認が必要になることがあります。

## 完了を確認する

プランが一覧に保存され、外部AIにプロンプトを直接登録したことを確認します。結果を取り込んだ後は、履歴で検証状態とスコアの反映状況を確認してください。
