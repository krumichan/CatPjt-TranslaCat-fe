## 웹 AI 학습 계획 만들기

웹 AI 계획은 외부 AI에서 진행할 학습 조건과 결과 전송 방법을 준비하는 기능이에요. **계획을 저장하는 것만으로 외부 AI에 예약이 등록되지는 않아요.** 복사한 프롬프트를 사용할 웹 AI에 직접 등록해 주세요.

1. 학습 설정의 **웹 AI 학습 계획**에서 계획 관리 화면을 열어요. 기본 설정과 오늘 사용할 키워드 준비 상태를 확인해요.
2. **새 계획**을 눌러 이름을 정해요. 언어는 현재 유효한 기본 학습 설정을 따라요.
3. 매일·매주·매월 중 반복 방식을 고르고 요일 또는 일자, 시각, 시간대를 정해요. 매월은 그 달에 없는 날짜를 건너뛰며 마지막 날도 선택할 수 있어요.
4. Writing·Reading·Speaking·Listening의 세부 유형과 난이도별 문제 수를 정해요. 문제를 요청할 항목은 1개 이상 필요해요.
5. 기본 키워드를 사용할지, 이 계획만의 키워드를 고를지 정해요. 원하는 상황과 주제도 선택적으로 적을 수 있어요.
6. **학습 계획 저장**을 눌러요.

## 프롬프트 복사와 연동

저장 후 **프롬프트 복사** 또는 **연동 프롬프트 만들기**를 눌러 실제 복사할 내용을 준비하고 확인해요. 복사가 차단되면 **전체 선택**으로 직접 복사해 주세요.

프롬프트에는 **계획 전용 연결 키**가 포함돼요. 사용할 웹 AI에만 붙여 넣고 공개 게시물이나 공유 문서에 올리지 마세요. 처음 프롬프트를 준비하거나 **연결 키 교체**를 사용하면 기존 키가 바뀌므로, 이미 등록한 예약에도 새 프롬프트를 넣어야 해요. 같은 페이지에서 다시 복사하는 것은 키를 교체하지 않아요. **연동 해제**를 하면 기존 프롬프트로는 연결할 수 없어요.

HTTP 요청을 지원하는 웹 AI는 문제를 가져오고 결과를 전송할 수 있어요. 이때 서비스 주소에 외부에서 접근할 수 있어야 해요. HTTP를 지원하지 않는 AI는 프롬프트로 한 회차를 학습한 뒤 결과 JSON을 직접 가져오세요. 외부 AI의 예약 지원 여부와 실행 상황도 해당 서비스에서 확인해 주세요.

## 결과 JSON 가져오기와 검증

1. 계획의 **학습 결과 가져오기**에서 이번 회차의 전송 프롬프트를 준비해요.
2. 웹 AI의 안내대로 학습하고 결과 JSON을 받아요.
3. **웹 AI 결과 JSON**에 그대로 붙여 넣고 **결과 저장 및 AI 검증**을 눌러요. 한 번에 10문항까지 나누어 가져올 수 있어요.
4. [학습 이력](/ko/language-learning/history)의 **웹 AI**에서 검증 상태, 학습 피드백, 웹 AI 원문을 확인해요.

외부 AI가 준 참고 점수와 TranslaCat에 반영되는 점수는 다를 수 있어요. **검증 완료된 문항만** 점수에 반영돼요. 지문·음성 등 평가 근거가 부족하거나 난이도·학습 언어가 맞지 않으면 점수 미반영 또는 코칭으로 남을 수 있어요. 상태와 이유를 함께 읽어 주세요.

검증 실패 시 **AI 검증 재시도**를 사용할 수 있어요. 이미 검증 중이거나 재시도 한도에 도달한 경우에는 표시된 안내를 따라 주세요. 저장된 답안과 원문은 보존돼요. 언어 설정을 바꿨거나 계획을 일시 중지했다면 새 프롬프트 준비 또는 계획 상태 확인이 필요할 수 있어요.

## 완료 확인

계획이 목록에 저장됐는지, 외부 AI에 프롬프트를 직접 등록했는지 확인해요. 결과를 가져온 뒤에는 검증 상태와 점수 반영 여부를 이력에서 확인해 주세요.
