[Writing](/en/language-learning/writing) asks you to create sentences in your study language using a source text or situation. Complete your learning settings and initial level test first.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to use the feature with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Choose a format

On PC, choose **Today's practice → Writing**; on mobile, choose **Practice → Writing**. Click **Start this format (이 형식 시작하기)** on the format you want. A format already started shows **Continue learning**, **View evaluation progress**, or **View results** instead.

| Format | What you write |
| --- | --- |
| Translation writing | Translate naturally into your study language while preserving the source meaning. |
| Guided writing | Build sentences that satisfy the given facts, required content, and answer conditions. |
| Free writing | Express an opinion, experience, or plan about the supplied topic. |

Choosing a format prepares its question set. Each format has a separate set, so you can complete one or continue with another. The question count follows your current learning settings.

## Write and request AI evaluation

1. Read the question and conditions, then write in **My answer (내 답변)** using the requested study language.
2. To evaluate one question, click **Get AI evaluation (AI 평가 받기)**.
3. To evaluate the set together, answer all prepared, unevaluated questions and click **Evaluate all ○ answers**. The **Evaluate together** area shows how many answers remain.
4. When evaluation finishes, review the score, strengths and improvements, expression corrections, suggested answer, and explanation.

PC gives questions more horizontal space. On mobile, scroll from the question to its answer field and feedback. Submission works the same way.

**Draft saved automatically** means your unfinished text is stored in this browser. Submit the answer if you need to access it from another device. After submission, **AI evaluation in progress** means the answer is saved on the server; evaluation continues if you refresh or open another menu.

## Preparation and retries

Start with questions that are ready. Your current answers remain while the rest are prepared. If preparation stops, use **Retry preparing remaining questions**. The evaluate-all button becomes available after question preparation and answer entry are complete.

If evaluation fails, check your text and click **Evaluate with AI again**. You can edit the answer before retrying. If only some evaluations fail, follow the instructions on those questions.

**Replace unanswered questions** replaces questions you have not answered yet. Check the remaining allowance first. It does not restart questions already submitted.

## Review after completion

Choose **Select another format** to try another writing activity, or **View results on dashboard**. Past answers and feedback appear under **Writing** in [learning history](/en/language-learning/history). You can submit a review answer only when a review field is provided. Existing records remain viewable after the review deadline.

Today's questions keep their generation-time settings. If you change languages, question counts, or keywords later, check the effective date. Completed evaluations can be used to adjust your learning profile.

## Check that you are done

Check your answer and its processing status on the result screen. If evaluation is still running, read the feedback when it finishes. You can reopen saved results in learning history.
