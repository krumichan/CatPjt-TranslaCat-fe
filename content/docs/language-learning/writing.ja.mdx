[Writing](/ja/language-learning/writing)は原文や状況を読み、学習言語で自分の文章を作る活動です。学習設定と初回レベルテストを完了して利用してください。

<Callout title="操作を始める前に">ガイドはログインなしで読めます。実際の操作は自分のアカウントでログインして進めてください。画像は説明用のサンプルデータを使用した実際の画面です。</Callout>

## 形式を選ぶ

PCは **今日の学習 → Writing**、モバイルは **学習 → Writing** を開きます。希望する形式の開始ボタンを押してください。開始済みの形式では、続きからの学習、評価の進捗、結果を見るボタンが表示されます。

| 形式 | 書く内容 |
| --- | --- |
| 翻訳作文 | 原文の意味を保ち、学習言語で自然に翻訳します。 |
| ガイド作文 | 与えられた事実、必須内容、回答条件に沿って文章を作ります。 |
| 自由作文 | テーマに合わせて意見・経験・計画などを表現します。 |

形式を選んだ時に、その問題セットを準備します。3種類はそれぞれ独立しているので、1種類だけでも、別の形式を続けて学んでも構いません。問題数は現在の学習設定に応じて表示されます。

## 回答とAI評価

1. 問題と条件を読み、**自分の回答** に学習言語で入力します。
2. 1問ずつ評価する場合は **AI評価を受ける** を押します。
3. 一括評価する場合は準備済みの未評価問題すべてに回答し、**○問をまとめてAI評価** を押します。未入力の数は **まとめて評価** で確認できます。
4. 完了後にスコア、良かった点と改善点、表現の修正、推奨回答、解説を確認します。

PCでは広い画面で問題を読み、モバイルでは問題の下の入力欄と評価結果までスクロールして確認します。送信方法は共通です。

**自動保存済み** は、下書きが現在のブラウザーに保存されたことを示します。他の端末でも確認したい回答は送信してください。**AI評価中です** と表示されたら回答はサーバーに保存済みです。再読み込みや別メニューへの移動後も評価は継続します。

## 準備と評価の再試行

準備済みの問題から回答できます。残りの問題の準備中も入力は保持されます。準備が中断した場合は残りの問題の準備を再試行してください。一括評価は必要な問題の準備と回答入力がそろうと利用できます。

評価に失敗した場合は保存された回答を確認し、**AI評価を再試行** を押します。回答を修正してから再依頼することもできます。一部だけ失敗した場合は該当問題の案内に従ってください。

未回答問題の変更ボタンは、まだ回答していない問題を変更します。残り回数を確認して利用してください。

## 完了後の復習

別の形式に進むか、ダッシュボードで結果を確認します。過去の回答とフィードバックは[学習履歴](/ja/language-learning/history)の **書く** で振り返れます。復習入力欄がある問題のみ再回答できます。再回答の期限が過ぎても過去の記録は確認できます。

今日の問題は生成時の設定を基準に保持されます。その後、言語・問題数・キーワードを変更した場合は適用予定日を確認してください。完了した評価は、その後の学習プロフィールの補正に利用されます。

## 完了を確認する

結果画面で自分の回答と処理状況を確認してください。評価中の場合は完了後にフィードバックを読み、保存された結果は学習履歴で開けます。
