[Writing](/ko/language-learning/writing)은 원문과 상황을 보고 학습 언어로 직접 문장을 만드는 활동이에요. 학습 설정과 첫 레벨 테스트를 마친 뒤 이용해 주세요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 유형 선택하기

PC에서는 **오늘의 학습 → Writing**, 모바일에서는 **학습 → Writing**을 선택해요. 원하는 유형에서 **이 형식 시작하기**를 눌러요. 이미 시작한 유형은 **이어서 학습하기**, **평가 진행 상황 보기**, **결과 보기**로 표시돼요.

| 유형 | 작성할 내용 |
| --- | --- |
| 번역 작문 | 원문의 의미를 유지하며 학습 언어로 자연스럽게 번역해요. |
| 가이드 작문 | 주어진 사실·반드시 전달할 내용·답변 조건에 맞춰 문장을 만들어요. |
| 자유 작문 | 제시된 주제에 맞춰 내 의견·경험·계획 등을 표현해요. |

유형을 선택할 때 해당 문제 세트를 준비해요. 세 유형은 각각 별개의 세트라서 하나만 풀어도 되고, 다른 유형을 이어서 학습해도 돼요. 문제 수는 현재 학습 설정에 따라 표시돼요.

## 답변 작성과 AI 평가

1. 문제와 작성 조건을 읽고 **내 답변**에 학습 언어로 입력해요.
2. 한 문제씩 평가받으려면 **AI 평가 받기**를 눌러요.
3. 한 번에 평가하려면 준비된 미평가 문제를 모두 작성한 뒤 **○개 모두 AI 평가**를 눌러요. 남은 답변 수는 **한 번에 평가하기** 영역에서 확인해요.
4. 평가가 끝나면 점수, 잘한 점과 보완할 점, 표현 교정, 추천 답안과 해설을 살펴봐요.

PC에서는 넓게 펼쳐진 문제를 읽고, 모바일에서는 문제 아래의 입력란과 평가 결과를 스크롤하며 확인해요. 제출 동작은 같아요.

**자동 임시 저장됨**은 현재 브라우저에 작성 중인 답변을 보관했다는 뜻이에요. 다른 기기에서도 보려면 답변을 제출해 주세요. 제출 후 **AI 평가 중입니다**가 표시되면 답변은 서버에 저장된 상태이고, 새로고침하거나 다른 메뉴로 이동해도 평가가 계속돼요.

## 문제 준비와 다시 시도

준비된 문제부터 풀 수 있어요. 나머지 문제를 만들고 있을 때도 현재 답변은 유지돼요. 준비가 중단되면 **나머지 문제 준비 재시도**를 눌러요. 모든 문제를 한꺼번에 평가하는 버튼은 문제 준비와 답변 입력이 끝나야 사용할 수 있어요.

평가가 실패하면 작성한 답변을 확인하고 **다시 AI 평가**를 눌러요. 답변을 수정한 뒤 다시 요청할 수도 있어요. 여러 문제 중 일부만 실패했다면 해당 문제의 안내를 따라 재시도해 주세요.

**미응답 문제 바꾸기**는 아직 답하지 않은 문제를 바꿔요. 남은 횟수를 확인하고 사용해 주세요. 이미 제출한 문제까지 새로 시작하는 기능은 아니에요.

## 완료 후 복습하기

**다른 유형 선택**으로 다른 작문을 시작하거나 **대시보드에서 결과 보기**로 이동해요. 지난 답변과 피드백은 [학습 이력](/ko/language-learning/history)의 **쓰기**에서 확인할 수 있어요. 복습 입력란이 제공되는 문제만 새 답변을 제출할 수 있으며, 복습 기한이 지나도 기존 기록은 볼 수 있어요.

오늘의 문제는 생성 당시 설정을 기준으로 유지돼요. 이후 언어·문제 수·키워드 설정을 바꿨다면 적용 예정일을 확인해 주세요. 완료된 평가 결과는 이후 학습 프로필 보정에 활용돼요.

## 완료 확인

결과 화면에서 내 답변과 처리 상태를 확인해 주세요. 평가 중이라면 완료 후 피드백을 읽고, 저장된 결과는 학습 이력에서 다시 열 수 있어요.
