title: Translate and listen to an episode
description: Translate an episode, then play the original Japanese text or the available translation.
---

## Open and translate an episode

1. Choose an episode in the work’s contents.
2. If the translation is not ready, select **Translate the episode** in the reader.
3. Read the sentences as they become available. If some sections fail, you can retry individual sentences or continue the unfinished sections without losing the completed sentences.

## Listen and move between episodes

1. In the control bar below the text, select **OPEN**.
2. Select **Read all source text** for Japanese audio, or **Read all translation** once the translation is ready.
3. Use **Pause**, **Resume**, **Stop**, **Playback speed**, or **Follow the current sentence** as needed.
4. Use **PREV / NEXT** to move between episodes and **OPEN → LIST** to return to the contents.

<Callout title="What the audio covers">
  OpenAI-generated audio reads the body of the current episode. It excludes the title, preface and afterword. English translation is available only on supported platforms.
</Callout>
