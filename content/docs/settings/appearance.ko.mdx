title: 화면 언어와 테마 바꾸기

---

서비스 버튼과 메뉴를 읽을 언어, 화면의 밝기를 바꾸는 작업이에요. 채팅 번역 언어나 학습 언어와는 다른 설정이에요.

화면 언어는 **한국어·일본어·영어와 학습 모드** 중에서 고를 수 있어요. 서비스 언어 메뉴에서 **EN**을 선택하면 영어 메뉴로 바뀌어요. 가이드의 언어 메뉴는 설명서 언어만 바꾸며, 서비스 화면 언어는 여기에서 따로 선택해요.

## 기기에 맞는 버튼 찾기

<Tabs items={["PC", "모바일"]} groupId="settings-device-ko">
  <Tab value="PC">
    1. 서비스 상단의 **언어 버튼(국기 또는 EN)**을 열고 화면 언어를 선택해요. 영어는 **EN**이에요.
    2. 옆의 **해·달 모양 버튼**으로 밝은 화면과 어두운 화면을 전환해요.

    <GuideScreenshot src="/images/guides/ko/language-pc.jpg" alt="서비스 상단의 언어 메뉴와 테마 버튼" title="PC: 상단 언어·테마 버튼" caption="언어·테마 버튼 위치를 보여주는 예시예요. 현재 언어 메뉴에서 EN을 고르면 영어 화면으로 바뀌어요." width={1280} height={600} step={1} locale="ko" />
  </Tab>
  <Tab value="모바일">
    1. 왼쪽 위 **☰ 메뉴**를 열어요.
    2. 메뉴 맨 아래 **언어 버튼(국기 또는 EN)**에서 언어를 선택해요. 영어는 **EN**을 눌러요.
    3. 같은 영역의 **테마 버튼**으로 화면 밝기를 전환해요.

    <GuideScreenshot src="/images/guides/ko/language-mobile.jpg" alt="모바일 전체 메뉴 아래의 언어 메뉴와 테마 버튼" title="모바일: 전체 메뉴 맨 아래" caption="버튼 위치를 보여주는 예시예요. 좁은 화면에서는 전체 메뉴 아래쪽에서 언어와 테마를 변경하며, 영어 화면은 언어 메뉴의 EN으로 선택해요." width={390} height={844} step={1} locale="ko" />
  </Tab>
</Tabs>

## 완료 확인

메뉴와 버튼의 언어, 배경 밝기가 바뀌었는지 확인해요. PC 창이 좁다면 모바일 안내를 참고해 주세요. [처음 시작하기](/ko/docs/getting-started#화면-언어-바꾸기)에서도 기기별 화면을 볼 수 있어요.
