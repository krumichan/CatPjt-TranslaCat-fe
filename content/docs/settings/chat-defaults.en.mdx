Save your preferred chat languages and display options so you do not need to configure every room from scratch.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to make changes with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Set your chat defaults

Open the **Chat settings (채팅 설정)** card in [Settings](/en/settings), or open [Chat settings directly](/en/settings/chat).

1. Choose **My language (내 언어)**.
2. Choose **Other language / Incoming translation language**.
3. Set **Show original** and **Show translation** as you prefer.
4. Click **Save (저장)** and check the confirmation.

Korean, Japanese, and **English** are available for chat languages. These defaults are used when entering a room without saved room-specific settings. **Language settings changed inside a room apply only to that room** and take precedence over the defaults. This is also separate from the application's display language. Continue with the [chat guide](/en/docs/chat) for room-specific settings and translation.

If no personal defaults exist, system defaults may be displayed. **Reload** fetches the saved values again, so decide whether to save your current edits first.

## Check that you are done

Check the save confirmation. Reload saved settings to verify the language and display values. For an existing room with its own settings, check that room's values too.
