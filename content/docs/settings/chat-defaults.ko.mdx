채팅방마다 반복해서 설정하지 않도록 내 기본 언어와 표시 방법을 저장하는 작업이에요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 채팅의 기본 언어 설정하기

[설정](/ko/settings)의 **채팅 설정** 카드 또는 [채팅 설정 화면](/ko/settings/chat)을 열어요.

1. **내 언어**를 선택해요.
2. **상대 언어 / 수신 번역 언어**를 선택해요.
3. **원문 표시**와 **번역문 표시**를 원하는 대로 설정해요.
4. **저장**을 누르고 완료 안내를 확인해요.

여기서 저장한 값은 새로 입장하거나 방별 설정이 없는 채팅방의 초기값으로 쓰여요. **채팅방 안에서 바꾼 언어 설정은 그 방에만 적용**돼요. 화면 언어를 한국어·일본어로 바꾸는 것과도 달라요. [채팅 가이드](/ko/docs/chat)에서 방별 설정과 번역 흐름을 이어서 확인해 보세요.

개인 기본값이 아직 없으면 시스템 기본값이 표시될 수 있어요. **다시 불러오기**는 저장된 값을 다시 조회하므로 작성 중인 값을 저장할지 먼저 확인해 주세요.

## 완료 확인

저장 완료 안내를 확인해요. 저장한 설정을 다시 불러와 언어와 표시 값이 유지되는지 확인할 수 있어요. 방별 설정이 있는 기존 방에서는 해당 방 설정을 확인해 주세요.
