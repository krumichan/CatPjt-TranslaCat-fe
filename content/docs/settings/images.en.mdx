Open **My profile (내 프로필)** from the top-right profile menu and scroll down to image management.

<Callout title="Before you begin">You can read this guide without signing in. Sign in to make changes with your own account. Service links open the English interface. Screenshots show the Korean interface with example data; Korean labels in parentheses help you compare the two.</Callout>

## Profile and background images

Manage one image of each type under **Manage profile images** near the bottom of your profile.

| Image | File formats | Maximum size |
| --- | --- | --- |
| Profile image | JPEG, PNG, WEBP | 5 MB |
| Profile background | JPEG, PNG, WEBP | 10 MB |

1. Click **Choose image (이미지 선택)** and choose a file. If an image already exists, the button says **Replace image**.
2. Check the **Preview before upload**. Use **Clear selection** if you chose the wrong file.
3. Click **Upload (업로드)** and check its completion notice. Choosing a file alone does not save it.

Uploading a new image replaces the existing one. **Delete (삭제)** removes the currently registered image of that type. Nickname/introduction saving and image uploading are separate actions; check each completion notice.

## Check that you are done

Check the upload or delete confirmation and the current image. If the change did not apply, check the format, file size, and whether the upload completed.
