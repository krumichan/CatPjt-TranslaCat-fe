오른쪽 위 프로필 메뉴의 **내 프로필**을 열고, 아래로 스크롤해 이미지 관리 영역을 찾아요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 프로필 이미지와 배경 이미지

프로필 화면 아래의 **프로필 이미지 관리**에서 각각 한 장씩 관리해요.

| 항목 | 파일 형식 | 최대 용량 |
| --- | --- | --- |
| 프로필 이미지 | JPEG, PNG, WEBP | 5 MB |
| 프로필 배경 이미지 | JPEG, PNG, WEBP | 10 MB |

<GuideScreenshot src="/images/guides/ko/profile-images.jpg" alt="프로필 이미지와 배경 이미지 관리 화면" title="이미지 종류별 선택·업로드" caption="프로필 화면 아래쪽에 이미지 관리 영역이 있어요. PC는 두 종류가 나란히, 좁은 화면은 세로로 이어져요. 파일 선택 후 업로드까지 완료해 주세요." width={1280} height={900} step={1} locale="ko" />

1. **이미지 선택**을 눌러 파일을 골라요. 기존 이미지가 있으면 **이미지 교체**로 표시돼요.
2. **업로드 전 미리보기**를 확인해요. 잘못 골랐다면 **선택 취소**를 눌러요.
3. **업로드**를 눌러 반영하고 완료 안내를 확인해요. 파일을 선택하는 것만으로는 저장되지 않아요.

새 이미지를 업로드하면 기존 이미지가 교체돼요. **삭제**는 현재 등록된 해당 이미지를 지워요. 닉네임·자기소개 저장과 이미지 업로드는 별도 작업이므로 각각 완료 안내를 확인해 주세요.

## 완료 확인

업로드·삭제 완료 안내와 현재 이미지를 확인해요. 반영되지 않으면 파일 형식·용량과 업로드 완료 여부를 확인해 주세요.
