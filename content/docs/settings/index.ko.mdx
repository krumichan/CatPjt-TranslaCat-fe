내 정보를 바꾸거나 서비스의 기본값을 관리할 때 필요한 작업을 골라보세요. 처음이라면 **프로필과 설정 열기**부터 따라가면 돼요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 준비 중인 설정 항목

설정 목록의 **일반 설정**, **음성 번역 설정**, **가계부 설정**은 **준비 중**, **AI 음성 읽기 설정**은 **예정**으로 표시돼요. 이 카드는 현재 열 수 없어요. 음성 번역의 언어·녹음 옵션과 가계부의 카테고리·목표 등은 각각의 기능 화면에서 조작해 주세요.

학습 언어, 키워드, 웹 AI 연동은 [언어학습의 설정 가이드](/ko/docs/language-learning/settings-history)에서 안내해요.

## 도움이 필요할 때

화면을 불러오지 못하면 다시 불러오기를 누르고 로그인 만료 안내가 있으면 재로그인해 주세요. 각 작업의 완료 확인에서 저장·업로드 상태를 확인할 수 있어요. 해결되지 않으면 [고객센터 가이드](/ko/docs/support)를 참고해 주세요. 문의에는 비밀번호나 인증 코드를 넣지 말고 문제 화면과 안내를 알려 주세요.
