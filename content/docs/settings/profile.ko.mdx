닉네임과 자기소개를 바꾸고 친구 추가나 가계부 초대에 쓸 고유 ID를 확인하는 작업이에요.

<Callout title="따라 하기 전에">가이드는 로그인 없이 읽을 수 있어요. 실제 작업은 내 계정으로 로그인해 진행해 주세요. 사진은 예시 데이터를 넣어 촬영한 실제 화면이에요.</Callout>

## 닉네임과 자기소개 바꾸기

1. [내 프로필](/ko/settings/profile)을 열어요.
2. **프로필 수정**에서 **닉네임**과 **자기소개**를 입력해요. 닉네임은 필수이며 30자 이내, 자기소개는 200자 이내로 작성해요.
3. **저장**을 누르고 **프로필을 저장했습니다.** 안내를 확인해요.

**취소**는 편집 중인 글을 마지막으로 불러온 값으로 되돌려요. PC에서는 미리보기와 수정 영역이 나란히 보이고, 모바일에서는 미리보기 아래로 스크롤하면 수정 영역이 나와요.

## TranslaCat ID 확인하기

프로필과 [설정](/ko/settings) 상단에서 **TranslaCat ID**를 확인하고 복사 버튼으로 복사할 수 있어요. 친구 추가나 가계부 초대에 사용하는 고유 ID예요. 닉네임과 달리 이 화면에서 수정할 수 없어요.

## 완료 확인

저장 완료 안내를 확인하고 프로필 미리보기의 이름과 소개를 확인해요. ID를 복사했다면 초대할 상대에게 전달할 때 닉네임과 구분해 주세요.

저장 버튼이 비활성이라면 바꾼 내용이 있는지, 이미 저장 중인지 확인해요. 프로필을 불러오지 못했다면 **다시 불러오기**를 누르고, 로그인 만료 안내가 있으면 재로그인해 주세요.
