Support includes **1:1 inquiries**, **Notices**, and **Received messages**. If you have a question or encounter an error, create an inquiry and continue the conversation in that same thread.

This guide is public. Using [Support](/en/support) requires you to sign in. Service links open the **English interface**. Screenshots show the **Korean interface** with example names and messages. Korean labels in parentheses help you compare the pictured controls with the English instructions. Select an image to enlarge it.

## Troubleshooting

| Situation | What to check |
| --- | --- |
| Your inquiry is missing | Check the signed-in account, status filter, and search term, then select **Refresh (새로고침)** in Support. |
| You cannot add another reply | Check whether the inquiry is closed. Select **Reopen inquiry (문의 다시 열기)**. |
| You do not have permission to view something | Check that the inquiry or received message belongs to the account you are signed in to. |
| A message says the content has changed | Select **Refresh (새로고침)**, check the latest state, and try again. |
| A list could not be loaded | Check the connection and select **Try again (다시 시도)**. |

You can also find instructions in the [Voice translation](/en/docs/voice), [Account books](/en/docs/account-books), [Chat](/en/docs/chat), [Language learning](/en/docs/language-learning), and [Profile and settings](/en/docs/settings) guides.
