サポートでは **お問い合わせ**、**お知らせ**、**受信メッセージ** を確認できます。質問や不具合がある場合はお問い合わせを送り、同じお問い合わせの中でやり取りを続けられます。

このガイドはログインせずに読めます。[サポートの利用](/ja/support)にはログインが必要です。画面内のお問い合わせや名前はガイド用のサンプルです。画像を押すと拡大できます。

## 必要な操作を選ぶ

<Cards>
  <Card title="サポートを開く" href="/ja/docs/support/open">サポートからお問い合わせ、お知らせ、受信メッセージを開きます。</Card>
  <Card title="お問い合わせを送る" href="/ja/docs/support/inquiries">利用中の質問や不具合をお問い合わせとして送信します。</Card>
  <Card title="回答を確認して追加の質問を送る" href="/ja/docs/support/replies">自分のお問い合わせを探し、回答の確認、追加の質問や終了の操作を行います。</Card>
  <Card title="お知らせを確認する" href="/ja/docs/support/notices">新しい情報や利用案内を読み、緊急のお知らせの表示方法を確認します。</Card>
  <Card title="受信メッセージを確認して問い合わせる" href="/ja/docs/support/messages">運営チームから自分に届いたメッセージを読み、関連するお問い合わせを作成します。</Card>
</Cards>

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| お問い合わせが見つかりません | ログイン中のアカウント、状態の絞り込み、検索語を確認し、サポートの **更新** ボタンを押します。 |
| 追加の質問を送れません | 終了したお問い合わせの場合は **問い合わせを再開** を押します。 |
| 閲覧する権限がありませんと表示されます | 自分のお問い合わせ・受信メッセージか、ログイン中のアカウントが正しいか確認します。 |
| 内容が更新されたと表示されます | **更新** して最新の状態を確認し、再試行します。 |
| 一覧を読み込めません | 接続を確認し、**再試行** を押します。 |

使い方は [音声翻訳](/ja/docs/voice)、[家計簿](/ja/docs/account-books)、[チャット](/ja/docs/chat)、[言語学習](/ja/docs/language-learning)、[プロフィールと設定](/ja/docs/settings) ガイドでも確認できます。
