title: 고객센터
description: 공지사항과 받은 메시지를 확인하고, 1:1 문의에서 답변과 추가 문의를 이어 가는 방법을 안내해요.
---

고객센터에서는 **1:1 문의**, **공지사항**, **받은 메시지**를 확인할 수 있어요. 궁금한 점이나 오류가 생기면 문의를 남기고 같은 문의 안에서 답변을 이어 가세요.

이 가이드는 로그인 없이 읽을 수 있으며, [고객센터 이용](/ko/support)에는 로그인이 필요해요. 캡처의 문의 내용과 이름은 가이드용 예시예요. 이미지를 누르면 확대할 수 있어요.

## 문제가 생겼을 때

| 상황 | 먼저 확인해 주세요 |
| --- | --- |
| 문의가 목록에 없어요 | 로그인한 계정, 문의 상태와 검색어를 확인하고 고객센터의 **새로고침** 버튼을 눌러요. |
| 답변을 더 남길 수 없어요 | 문의가 종료 상태인지 확인하고 **문의 다시 열기**를 눌러요. |
| 내용을 볼 권한이 없다고 나와요 | 내 문의 또는 나에게 온 메시지인지, 로그인 계정이 맞는지 확인해요. |
| 내용이 변경됐다는 안내가 나와요 | **새로고침** 후 최신 상태를 확인하고 다시 시도해요. |
| 목록을 불러오지 못했어요 | 연결 상태를 확인하고 **다시 시도**를 눌러요. |

기능 사용법은 [음성 번역](/ko/docs/voice), [가계부](/ko/docs/account-books), [채팅](/ko/docs/chat), [언어학습](/ko/docs/language-learning), [프로필과 설정](/ko/docs/settings) 가이드에서도 확인할 수 있어요.
