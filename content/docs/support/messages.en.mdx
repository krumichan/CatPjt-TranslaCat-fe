---
title: Read messages and ask about them
description: Read a message sent to you by the support team and start a linked private inquiry about it.
---

Start by [opening Support](/en/docs/support/open).

## Follow these steps

1. Open **Received messages (받은 메시지)** to find messages the team sent to you.
2. Select a title to read the message. Only its recipient and administrators can read a received message.

3. If you have a question about the message, select **Ask about this message (이 메시지에 대해 문의하기)**. A new private inquiry form opens with that message linked.
4. Check the title and content, then select **Submit inquiry (문의 등록)**. Continue the conversation in that inquiry's replies. Use **View related message (관련 메시지 보기)** in the inquiry to reopen the original message.

## Check the result

Check that you can read the message. If you submitted an inquiry, continue the conversation in its details, where the related message is linked.
