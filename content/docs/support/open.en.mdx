## Follow these steps

<Tabs items={["PC", "Mobile"]} groupId="guide-device-en">
  <Tab value="PC">
    1. Select **Support (고객센터)** in the left menu.
    2. In Support's own left menu, choose **1:1 inquiries / Notices / Received messages (1:1 문의 / 공지사항 / 받은 메시지)**.
    3. Select an item in the list on the right to read it.

  <Tab value="Mobile">
    1. Open the **☰ menu** at the top left and select **Support (고객센터)**.
    2. Choose **1:1 inquiries / Notices / Received messages (1:1 문의 / 공지사항 / 받은 메시지)** from the row above the Support content.
    3. Scroll the list and open an item. From a detail or compose screen, select **Back to list (목록으로)** to return.

The layout changes with screen width. Follow the Mobile instructions in a narrow PC window.

Select **User guide** next to the Support title for the overview. The **?** next to a list or a form opens the guide for that task in a new tab. In an inquiry, the **?** next to replies explains how to read them and follow up.

## Open from a notification

Select a Support notification in the top **Notification center (알림센터)** to open its notice, message, or inquiry. An inquiry-reply notification links to the relevant reply. Opening the details also updates the read status in the notification center.

If **Your spending analysis is ready** appears in the notification center at the top, select it to open the analysis result in the account book. It does not appear in Support's **Received messages** list. See the [account book guide](/en/docs/account-books) for more.

## Check the result

The list for the selected section should appear. If you have no inquiries yet, select the inquiry button to create your first one.
