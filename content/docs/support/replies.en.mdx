---
title: Read replies and follow up
description: Find your inquiry, read the support team's reply, ask follow-up questions, or close it.
---

Start by [opening Support](/en/docs/support/open).

## Follow these steps

In **1:1 inquiries (1:1 문의)**, find an inquiry with the **Inquiry status (문의 상태)** filter or **Inquiry search → Search button (문의 검색 → 검색 버튼)**. If there are several pages, use the previous/next page buttons below the list.

| Status | Meaning |
| --- | --- |
| Waiting for reply (답변 대기) | The team has not yet replied. |
| Answered (답변 완료) | A reply has been added. Open the inquiry to read it. |
| Closed (종료) | The inquiry has been resolved and closed. You can reopen it if necessary. |

## Read the reply and continue the conversation

1. Open the inquiry and read **Replies and follow-up inquiries (답변 및 추가 문의)**.

2. To ask another question or provide more information, enter **Follow-up content (추가 문의 내용)** below and select **Submit follow-up (추가 문의 등록)**.
3. To respond to a particular reply, select **Reply to this reply (이 답글에 답하기)** on it. The selected reply appears above the input. Select **×** to clear it if you chose the wrong reply.
4. When the issue is resolved, select **It's resolved (해결됐어요)** to close the inquiry. If you need more help later, select **Reopen inquiry (문의 다시 열기)** before adding a follow-up.

If sending fails, read the on-screen message. The follow-up draft is cleared only after it has been sent successfully, so you can check the connection and retry.

## Check the result

After sending a follow-up, check that it appears in the reply list. After selecting It's resolved, check that the inquiry status has changed to Closed.
