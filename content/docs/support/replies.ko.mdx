---

먼저 [고객센터 열기](/ko/docs/support/open)를 따라 화면을 열어 주세요.

## 순서대로 따라 하기

**1:1 문의** 목록에서 **문의 상태**를 고르거나 **문의 검색 → 검색 버튼**을 이용해 작성한 문의를 찾을 수 있어요. 여러 페이지가 있으면 아래 이전·다음 페이지 버튼으로 이동해요.

| 상태 | 뜻 |
| --- | --- |
| 답변 대기 | 운영팀의 확인과 답변을 기다리는 상태예요. |
| 답변 완료 | 답변이 등록된 상태예요. 문의를 열어 답글을 확인해 주세요. |
| 종료 | 해결되어 종료한 문의예요. 필요하면 다시 열 수 있어요. |

## 답변을 읽고 이어서 문의하기

1. 문의를 열고 **답변 및 추가 문의**에서 답글을 읽어요.

2. 더 물어보거나 추가 정보를 보낼 때는 아래 **추가 문의 내용**을 적고 **추가 문의 등록**을 눌러요.
3. 특정 답글에 이어 답하려면 그 답글의 **이 답글에 답하기**를 눌러요. 선택한 답글이 입력란 위에 표시돼요. 잘못 골랐다면 **×**로 대상을 해제해요.
4. 해결되면 **해결됐어요**를 눌러 종료해요. 종료 상태에서 도움이 더 필요하면 **문의 다시 열기**를 누른 뒤 추가 문의를 남겨요.

전송에 실패했다면 화면의 안내를 확인해 주세요. 추가 문의 초안은 성공적으로 전송된 뒤 비워지므로, 연결 상태를 확인하고 다시 시도할 수 있어요.

## 완료 확인

추가 문의를 보냈다면 답글 목록에 내용이 나타나는지 확인해요. 해결됐어요를 눌렀다면 문의 상태가 종료로 바뀌었는지 확인해요.
