You can read this guide without signing in. To use the feature, [sign in](/en/login) to your own account.

Open the [voice translation screen](/en/voice) to follow along.

## Manage saved history

Find a saved session under **Translation history (번역 이력)** near the bottom of the screen.

- Select a **Session title (세션 제목)** to expand the saved sentences. Each sentence shows the speaker, original text, and translation.
- Select the **Pencil icon / Edit title (제목 수정)**, enter a title, and select **Save (저장)**. Titles can contain up to 100 characters.
- Select **Refresh (새로고침)** if history is missing, or **Load more (더 보기)** if more sessions are available.
- If a sentence has original text but its translation failed, select **Retry translation (번역 재시도)** when available. The button may not appear for unsupported input languages or sentences that did not match the specified language.
- To remove a session, select its **Trash icon / Delete (삭제)** and confirm in the dialog.

## Check the result

Expand the session you want and check that you can read its sentences. After renaming, check the new title; after deletion, check that the session no longer appears.
