Read spoken audio as original text and translations. Choose where the sound comes from—**Microphone**, **System audio**, or **Meeting**—then start translating. Input and translation languages include **Korean, Japanese, and English**.

<Callout title="Before you start">
  This guide is public, but voice translation requires you to sign in. Use a browser where you can grant microphone or tab-sharing permissions. Speech recognition and translation require an internet connection.
</Callout>

Service links open the **English interface**. Screenshots show the **Korean interface** with example data; Korean names in parentheses identify the pictured controls. Interface language, guide language and translation language are separate choices.

## Troubleshooting

| Situation | What to check |
| --- | --- |
| A message asks you to check microphone permission | Allow microphone access in your browser's site permissions and start again. Check that the device microphone is not muted. |
| A message asks you to select a tab or screen with audio | Select the tab actually playing the sound and enable tab audio sharing. Sharing a silent screen alone will not let the session start. |
| Your browser does not support capture | Try Microphone mode. If you need tab or screen sharing, open a PC browser that supports it. |
| The input is too quiet or no sound is detected | Speak closer to the microphone or raise the volume of the shared video or meeting. Check for mute or pause. |
| The detected language differs from the specified language | End the session and start again with automatic detection or the actual input language. |
| Recognition is delayed, the server is busy, or translation fails | Check the connection and individual sentence errors. If the original text was saved, you may be able to retry translation from history. |
| The last audio could not be confirmed as processed | Check the last sentence in saved history. If the session is still open, try **End session (세션 종료)** again. |

If the issue continues, follow the [Support guide](/en/docs/support) and include the error message and input mode.
