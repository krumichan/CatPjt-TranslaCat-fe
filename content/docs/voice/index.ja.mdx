title: 音声翻訳

---

話した内容を原文と訳文で確認する機能です。音声の取り込み方に合わせて、**マイク**、**システム音声**、**会議**を選びます。

<Callout title="始める前に">
  ガイドはログインせずに読めますが、音声翻訳の利用にはログインが必要です。マイクやタブ共有の権限を許可できるブラウザで開いてください。音声認識と翻訳にはインターネット接続が必要です。
</Callout>

## 目的に合う操作を選ぶ

初めての場合は、**音声翻訳を開く → 入力モードを選ぶ → 言語・保存を設定 → 翻訳を開始・終了 → 履歴を確認**の順に進めましょう。

<Cards>
  <Card title="音声翻訳を開く" href="/ja/docs/voice/open">PC・モバイルで設定画面を開き、開始前の準備を確認します。</Card>
  <Card title="マイク・タブ・会議の入力を選ぶ" href="/ja/docs/voice/input-modes">音声の取り込み方に合うモードと権限を確認します。</Card>
  <Card title="言語と会話の保存を設定する" href="/ja/docs/voice/languages-storage">入力言語、翻訳先言語、テキストの保存を設定します。</Card>
  <Card title="リアルタイム翻訳を開始・終了する" href="/ja/docs/voice/live-translation">原文・訳文と接続状態を確認し、最後の文まで処理します。</Card>
  <Card title="保存した翻訳履歴を管理する" href="/ja/docs/voice/history">履歴の表示、タイトル変更、翻訳の再試行、削除を案内します。</Card>
</Cards>

## 困ったときは

| 状況 | 確認すること |
| --- | --- |
| マイクの権限を確認するよう案内される | ブラウザのサイト権限でマイクを許可して開始し直します。端末側のミュートも確認してください。 |
| 音声を含むタブ・画面を選ぶよう案内される | 実際に音声が再生されるタブを選び、タブの音声共有を有効にします。音声のない画面だけでは開始できません。 |
| ブラウザがキャプチャ機能に対応していない | マイクモードを試してください。タブ・画面共有が必要なら、対応するPCブラウザで開いてください。 |
| 入力音量が小さい、音声が入らない | マイクに近づくか、共有した動画・会議の音量を上げます。ミュート・一時停止も確認します。 |
| 検出された言語が指定言語と異なる | セッションを終了し、自動検出か実際の入力言語で開始し直します。 |
| 認識の遅延・混雑・翻訳エラーが出る | 接続状態と文ごとのエラーを確認します。保存済みの原文があれば、履歴から翻訳を再試行できます。 |
| 最後の音声処理を確認できなかった | 保存した履歴の最後の文を確認します。セッションが開いている場合は、**セッション終了**を再度試します。 |

解決しない場合は[サポートガイド](/ja/docs/support)を参考に、表示されたエラーと使用したモードをお知らせください。
