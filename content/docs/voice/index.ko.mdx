말하는 내용을 원문과 번역문으로 확인하는 기능이에요. **마이크**, **시스템 오디오**, **회의** 중에서 소리가 들어오는 방식을 고르고 번역을 시작해요.

<Callout title="시작 전에 준비해 주세요">
  가이드는 로그인 없이 읽을 수 있지만, 음성 번역을 사용하려면 로그인이 필요해요. 마이크나 탭 공유 권한을 허용할 수 있는 브라우저에서 열어 주세요. 음성을 인식하고 번역하려면 인터넷 연결이 필요해요.
</Callout>

## 하려는 작업을 골라 주세요

처음 사용한다면 **음성 번역 열기 → 입력 모드 고르기 → 언어·저장 설정 → 번역 시작·종료 → 저장 이력 확인** 순서로 진행해 보세요.

## 문제가 생겼을 때

| 상황 | 확인할 내용 |
| --- | --- |
| 마이크 권한을 확인하라는 안내가 나와요 | 브라우저의 사이트 권한에서 마이크 사용을 허용하고 다시 시작해요. 기기의 마이크 음소거도 확인해요. |
| 오디오가 포함된 탭·화면을 선택하라고 해요 | 실제 소리가 재생되는 탭을 선택하고 탭 오디오 공유를 켜요. 소리 없는 화면만 공유하면 시작할 수 없어요. |
| 브라우저가 캡처 기능을 지원하지 않아요 | 마이크 모드로 다시 시도해 보세요. 탭·화면 공유가 필요하다면 이를 지원하는 PC 브라우저에서 열어 주세요. |
| 입력이 작거나 소리가 들어오지 않아요 | 마이크에 가까이 말하거나 공유한 영상·회의의 재생 음량을 높여요. 음소거·일시 중지 상태인지도 확인해요. |
| 감지한 언어가 지정 언어와 다르다고 해요 | 세션을 종료하고 자동 감지 또는 실제 입력 언어로 새로 시작해요. |
| 인식 지연·서버 혼잡·번역 실패가 나와요 | 연결 상태와 문장별 오류를 확인해요. 저장된 원문이 있으면 이력의 번역 재시도를 사용할 수 있어요. |
| 마지막 음성 처리를 확인하지 못했어요 | 저장된 이력의 마지막 문장을 확인해요. 세션이 열려 있으면 **세션 종료**를 다시 시도해요. |

계속 문제가 생기면 [고객센터 가이드](/ko/docs/support)를 참고해 표시된 오류와 사용한 모드를 알려 주세요.
