[음성 번역 화면](/ko/voice)을 연 상태에서 진행해요.

## 입력 모드 고르기

| 모드 | 이런 때 사용해요 | 필요한 권한과 설정 |
| --- | --- | --- |
| **마이크** | 내가 말하는 내용을 번역할 때 | 브라우저의 마이크 권한을 허용해요. 결과에는 **내 음성**으로 표시돼요. |
| **시스템 오디오** | 영상이나 온라인 회의에서 들리는 소리를 번역할 때 | 소리가 재생되는 탭·화면을 선택하고 오디오 공유를 켜요. 결과에는 **상대방 음성**으로 표시돼요. |
| **회의** | 내 목소리와 상대방 소리를 함께 번역할 때 | 탭·화면 오디오 공유와 마이크 권한을 모두 허용해요. 두 입력은 **내 음성 / 상대방 음성**으로 구분돼요. |

시스템 오디오를 공유할 때는 **Teams나 YouTube가 실제로 재생되는 탭**을 골라 주세요. TranslaCat 탭을 고르면 번역하려는 상대방 소리가 들어오지 않을 수 있어요. 공유 창의 **탭 오디오 공유**도 켜야 해요. 공유한 화면에 오디오가 포함되지 않으면 시작할 수 없어요.

회의 모드에서는 헤드폰을 사용하면 상대방 소리가 내 마이크로 다시 들어오는 것을 줄일 수 있어요.

## PC·모바일에서 권한 준비하기

<Tabs items={["PC", "모바일"]} groupId="voice-mode-device-ko">
  <Tab value="PC">
    탭·화면 공유 창에서는 실제 소리가 나는 탭을 선택하고 **탭 오디오 공유**를 켜요. 회의 모드는 마이크도 함께 허용해요.
  </Tab>
  <Tab value="모바일">
    먼저 **마이크** 모드로 시작해 보세요. 브라우저가 오디오를 포함한 탭·화면 공유를 지원하지 않으면 시스템 오디오·회의 모드는 사용할 수 없어요. 이 경우 지원하는 PC 브라우저를 이용해 주세요.
  </Tab>
</Tabs>

## 완료 확인

번역하려는 소리에 맞는 모드가 선택되어 있고, 필요한 권한을 허용할 수 있는지 확인했어요.
