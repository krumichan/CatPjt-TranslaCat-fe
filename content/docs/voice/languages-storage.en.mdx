You can read this guide without signing in. To use the feature, [sign in](/en/login) to your own account.

Open the [voice translation screen](/en/voice) to follow along.

## Set languages and storage

1. Under **Input language (입력 언어)**, choose **Auto-detect (자동 감지)** or **Specify language (언어 직접 지정)**.
2. If you specify languages, choose the language actually being spoken for **My voice / Other person's voice (내 음성 / 상대방 음성)**. Meeting mode lets you set a separate language for each input.
3. Under **Translation language (번역 언어)**, choose the language you want to read.
4. Turn on **Save conversation (대화 내용 저장)** if you want to read the text again later.

Both input and translation support **Korean, Japanese, and English**. These settings are separate from the interface language chosen in the **Language** menu, and from the language of this guide. If the speech is already in the selected translation language, only the original text may appear because translation is unnecessary.

For example, to read an English speaker's words in Korean, select **English (영어)** for that input and **Korean (한국어)** as the translation language. To read Korean speech in English, reverse those choices. Auto-detect is also available if you do not want to specify the input language.

<Callout title="What is saved?">
  With conversation storage enabled, you can revisit finalized original text and translations in history. The original audio is not stored. If you do not want to save a conversation, turn this option off before starting.
</Callout>
