[음성 번역 화면](/ko/voice)을 연 상태에서 진행해요.

## 언어와 저장 여부 설정하기

1. **입력 언어**에서 **자동 감지** 또는 **언어 직접 지정**을 선택해요.
2. 직접 지정했다면 나타나는 **내 음성 / 상대방 음성** 항목에서 실제로 말할 언어를 골라요. 회의 모드에서는 두 입력의 언어를 각각 지정할 수 있어요.
3. **번역 언어**에서 결과를 읽고 싶은 언어를 선택해요.
4. 나중에 내용을 다시 보려면 **대화 내용 저장**을 켜요.

입력과 번역은 **한국어·일본어·영어**를 지원해요. 오른쪽 위 국기로 바꾸는 화면 표시 언어와는 별도 설정이에요. 입력한 음성과 번역 언어가 같아 번역이 필요하지 않으면 원문만 표시될 수 있어요.

<Callout title="무엇이 저장되나요?">
  대화 내용 저장을 켜면 확정된 원문과 번역 결과를 이력에서 다시 볼 수 있어요. 원본 음성은 저장하지 않아요. 저장하지 않을 대화라면 시작 전에 이 옵션을 꺼 주세요.
</Callout>
