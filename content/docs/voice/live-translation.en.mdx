## Start translation and read the results

1. Select **Start translation (번역 시작)** and allow the microphone or choose the tab to share in your browser's permission dialog.
2. Once the connection is ready, speak or play the shared video or meeting audio.
3. In **Live session (실시간 세션)**, check the input level and connection status. Look for the **Audio is being received (소리가 들어오고 있습니다)** message.
4. Read the original and translation under **Live translation (실시간 번역)**. In Meeting mode, also check each sentence's **My voice / Other person's voice (내 음성 / 상대방 음성)** label.

The current sentence and **Draft translation (임시 번역)** can change as audio processing continues. Wait until **Finalizing (확정 중)** and **Translating (번역 중)** have finished. AI may misrecognize noise or translate an expression differently, so compare the translation with the original before using it to communicate.

You cannot change the input mode or languages during translation. End the current session and start a new one to change them. Select **Cancel preparation (준비 취소)** to stop connection preparation.

## End a session

1. Select **End session (세션 종료)** when you no longer need translation. Even after scrolling, the control is available in the live session area below the app's top header.
2. Wait for **Processing final audio (마지막 음성 처리 중)** to change to **Complete (완료)**.
3. To use different settings, select **Start new session (새 세션 시작)**.

Wait for ending to finish before leaving the page so you can check the final sentence. If a message says the shared tab or microphone input has ended, end the session and select your input again.

For problems with microphone permission, volume, language mismatch, or the final audio, see [voice translation troubleshooting](/en/docs/voice#troubleshooting).

## Check the result

Check that final audio processing has finished and the session is marked complete. If storage was enabled, review the session in translation history below.
