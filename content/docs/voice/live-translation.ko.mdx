## 번역 시작하고 결과 읽기

1. **번역 시작**을 누르고 브라우저의 권한 요청에서 마이크 또는 공유할 탭을 선택해요.
2. 연결 준비가 끝나면 말을 하거나 공유한 영상·회의의 소리를 재생해요.
3. **실시간 세션**에서 입력 크기와 연결 상태를 확인해요. **소리가 들어오고 있습니다**라는 안내가 표시되는지 살펴보세요.
4. **실시간 번역**에서 원문과 번역을 읽어요. 회의 모드에서는 각 문장의 **내 음성 / 상대방 음성** 구분도 확인해요.

듣는 중인 문장과 **임시 번역**은 음성 처리가 진행되며 바뀔 수 있어요. **확정 중**, **번역 중** 안내가 끝난 결과까지 기다려 주세요. AI가 소음을 잘못 인식하거나 표현을 다르게 번역할 수 있으니, 전달할 내용은 원문과 함께 확인해 주세요.

번역 중에는 입력 모드와 언어를 바꿀 수 없어요. 변경하려면 현재 세션을 종료하고 새 세션을 시작해 주세요. 연결 준비를 중단하려면 **준비 취소**를 눌러요.

## 세션 종료하기

1. 더 이상 번역하지 않을 때 **세션 종료**를 눌러요. 스크롤 중에도 앱 상단 헤더 아래의 실시간 세션 영역에서 종료 버튼을 찾을 수 있어요.
2. **마지막 음성 처리 중** 안내가 끝나고 **완료**로 바뀌는지 확인해요.
3. 다른 설정으로 다시 시작하려면 **새 세션 시작**을 눌러요.

마지막 문장까지 확인하려면 페이지를 떠나기 전에 종료 처리가 끝날 때까지 기다려 주세요. 공유 탭이나 마이크 입력이 종료되었다는 안내가 나오면 세션을 종료한 뒤 입력을 다시 선택해요.

문제가 생기면 [음성 번역의 문제 해결](/ko/docs/voice#문제가-생겼을-때)에서 마이크 권한, 입력 음량, 언어 불일치와 마지막 처리 안내를 확인해 주세요.

## 완료 확인

마지막 음성 처리 중 안내가 끝나고 완료가 되었는지 확인해요. 저장을 켠 세션은 아래 번역 이력에서 다시 확인할 수 있어요.
