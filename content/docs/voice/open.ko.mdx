이 안내는 로그인 없이 읽을 수 있어요. 실제 기능은 [로그인](/ko/login) 후 내 계정에서 이용해 주세요.

[음성 번역 화면](/ko/voice)을 연 상태에서 진행해요.

## 음성 번역 열기

<Tabs items={["PC", "모바일"]} groupId="voice-device-ko">
  <Tab value="PC">
    1. 로그인 후 왼쪽 메뉴의 **음성 번역**을 클릭하거나 [음성 번역 화면](/ko/voice)을 열어요.
    2. **번역 세션 설정**에서 모드와 언어를 선택해요. 넓은 화면에서는 입력 모드가 가로로, 언어 설정이 두 열로 표시돼요.

  <Tab value="모바일">
    1. 로그인 후 왼쪽 위 **☰ 메뉴 → 음성 번역**을 누르거나 [음성 번역 화면](/ko/voice)을 열어요.
    2. 설정이 세로로 배치되므로 아래로 스크롤하며 언어와 저장 여부까지 확인해요.
    3. 처음에는 **마이크** 모드로 시작해 보세요. 시스템 오디오와 회의 모드는 브라우저가 **오디오를 포함한 탭·화면 공유**를 지원해야 사용할 수 있어요. 지원하지 않는 기기에서는 PC에서 이용해 주세요.

화면 너비에 따라 메뉴와 설정 배치가 바뀌어요. PC 창이 좁다면 모바일 안내를 참고해 주세요.

## 완료 확인

번역 세션 설정에서 입력 모드와 언어 항목을 확인할 수 있으면 준비됐어요.
